# Прогресс

Ветка разработки: `develop`. Обновляется после каждого этапа.

## 18.10.2026
**Готово**
- Требования (`docs/requirements.md`), утверждённый план (`docs/plan.md`), решения (`docs/decisions.md`).
- Исходные материалы заказчика без изменений: `legacy/fish_stock_forecast`, `legacy/src`, `legacy/data_catch`.
- Общая библиотека `libs/fishcommon`: настройки, атомарное хранилище с версиями, JWT и матрица прав, журнал, ошибки, проверка значений по схеме.
- Сервис **users**: вход, обновление токена, смена пароля, пользователи, роли (4), блокировка (вручную и после 10 неудачных попыток), запрет блокировки последнего администратора, журнал (фильтры, выгрузка Excel, хранение 365 дней).
- Сервис **data-model**: конструктор справочников, записи с версиями, проверка типов/обязательности/уникальности/ссылок, системные поля, водоёмы (37 предзаполнено), GeoJSON для карты, разбор GeoJSON/KML, 7 типов наборов данных по структуре данных Жайсана.
- Заготовки остальных 4 сервисов (/health), Docker Compose, nginx, запуск без Docker.

**Проверено**: `python -m pytest` — тесты users и data-model проходят.

**Ограничения среды**: Docker Hub недоступен из среды разработки — образы Docker здесь не собирались;
проверка `docker compose up` — на сервере / компьютере с Docker.

**Дальше**: оболочка Vue (вход, RU/KK, навигация), data-admin.

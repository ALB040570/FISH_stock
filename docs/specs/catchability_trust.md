# Уловистость: «Можно ли верить запасу» — сводка по видам и список идей

Статус: **утверждено заказчиком 22.10.2026** (сессия «Мониторинг — сверка со старым приложением»).
Реализует сессия, которая ведёт раздел «Мониторинг → Уловистость» (коммиты 7a0e400, 94aa4d9).
Часть А — делать сейчас. Часть Б — список идей, все одобрены заказчиком, порядок — после части А.

Основание: уловистость c — доля рыб возраста j из облавливаемой зоны, которая попадает в орудие;
запас = улов ÷ c, поэтому от c зависят запас, ПДУ НПЦ по возрастам и вход байесовской модели.
Таблица уловистости ценна не сама по себе, а как ответ: **насколько можно верить запасу и ПДУ вида**.

Общие правила (обязательны для А и Б):
- **Новых формул нет.** Только сравнения чисел, уже посчитанных запуском (этапы 1–2). Ничего не пересчитывать.
- **Пороги не придумывать.** Все пороги — правила в «Конструктор → Правила замечаний» (`/design/signal-rules`,
  `insights.RULES`, `GET/PUT /signal-rules`). У новых правил **значения по умолчанию нет**: пока ихтиолог не задал
  порог, показываем числа без цвета и с пометкой «порог не задан».
- Источник — основной запуск водоёма (иначе последний успешный), как у остальных представлений `calc_views.py`.

## Часть А. Сводный слайд «Можно ли верить запасу»

### Где
Вкладка «Уловистость» мониторинга: разделы становятся **«Сводка | Невод | Сеть»**, по умолчанию открыта «Сводка».
Год — те же стрелки ‹ 2024 › над слайдами (общий год раздела). Одна строка на вид. Щелчок по строке открывает
слайды вида в разделе «Невод» (как сейчас щелчок в таблице «все виды»). Щелчок по ячейке ведёт к слайду,
где видно причину: «на границах» → «Коэффициент уловистости» (невод или сеть — где сработала граница);
«согласие орудий» → «Запасы → Годовой запас»; «поколения» → «Запасы → Возрастная структура»;
«качество проб» → «Параметры года».

### Реализация
- Новое представление `ca_trust` в `services/dashboards/app/calc_views.py` по образцу `v_ca_species`
  (`columns`, `rows`, `default_view: "table"`, `row_action: "species"`, `notes`, `help`, `_common(...)`).
  Пояснение справа — в `calc_explain.py` (RU/KK).
- Данные: `run_payload("seine_catchability")` (fits невода, `c_lower_first`, `c_lower`, `c_upper`),
  `run_payload("stock_by_catch")["net"]` (fits сети, `c_lower`, `c_upper`), `run_table("stock_by_catch", "stock_by_age")`
  (окончательный запас по возрастам), `run_table("stock_by_catch", "yearly_stock")`.
- Вариант запаса — тот, что идёт в ПДУ: `variant = with_ages`, `method = on_stock`
  (переключатели вкладки «Запасы» сводку не меняют; в примечании слайда это написать).
- Правила замечаний сейчас передаются только части представлений (`main.py`, `_rules()`): передать и в `ca_trust`.
- Excel — тем же механизмом, что у остальных табличных слайдов (все колонки, включая «фразу-вывод»).

### Колонки
Возраст j — как везде в расчёте: j = 2 — это «1–2 года». Допуски сравнения с границей — как в
`fishcore/catchability_seine.py` (1e-4 для 0,01; 1e-3 для 0,1 и 0,8); для сети — 1e-3.

**1. Вид.**

**2. Запас на границах, %** (идея 1).
- Для выбранного года отмечаем возрасты j, где c невода равна своей границе (для первого возраста — `c_lower_first`
  0,01, для остальных — `c_lower` 0,1; сверху — `c_upper` 0,8) **или** c сети равна `c_lower` 0,1 / `c_upper` 0,8.
- Значение = Σ окончательного запаса (`stock_by_age`) по отмеченным возрастам ÷ Σ по всем возрастам × 100.
- Под числом мелко: какие возрасты и каким орудием («1–2, 2–3 · невод»). Нет отмеченных — «0 %».
- Правило `catch_bounds_share`: «Запас на границах уловистости больше, %» (без значения по умолчанию).

**3. Согласие орудий** (идея 3).
- Отношение годового запаса невода к сети за выбранный год (`yearly_stock`, gear «невод» / «сеть»), вид «2,0×».
- Если больше сеть — показывать «сеть 2,3× невода» (то же отношение, перевёрнутое для чтения).
- Под числом мелко: медиана отношения невод/сеть по всем годам («обычно 3,3×»).
- Нет одного из орудий (водоём только с сетями) — «одно орудие», без цвета. Запас сети 0 — «—».
- Правило `gears_disagree`: «Невод и сеть расходятся больше чем в, раз» (без значения по умолчанию;
  срабатывает при отношении > R или < 1/R).

**4. Проверка поколений** (идея 2).
- Для выбранного года y и каждого возраста j, если есть N(j−1, y−1) > 0 и N(j, y): поколение «выросло», если
  N(j, y) > N(j−1, y−1) · (1 + допуск/100). N — окончательный запас (`stock_by_age`).
- Значение: «k из n выросли». Под числом: наибольший рост с подписью поколения — «×43,6: 1–2 года в 2023 → 2–3 в 2024».
- Первый год ряда (нет y−1) — «—».
- Правило `cohort_growth`, два параметра без значений по умолчанию: «Рост поколения больше, %» (допуск) и
  «Сообщать, если выросло поколений больше, %» (доля k/n). Пока допуск не задан — считаем при допуске 0
  (это определение проверки: без миграции поколение не может стать больше), но цвет не ставим.

**5. Качество проб** (идея 4).
- Число рыб в пробе невода (`n_sample`) и R² сигмоиды (`r2`). Значки: «проба за все годы» (в `status` подгонки
  есть «проба за все годы» — параметры года взяты из сводной пробы, это не данные года), «мало рыб», «R² низкий».
- «мало рыб» — существующее правило `small_sample` («Минимум рыб в пробе»).
  **Внимание:** у него сейчас значение по умолчанию 30 — его не утверждал ихтиолог; вынести в открытые вопросы
  заказчику, до ответа оставить как есть.
- Новое правило `fit_r2_low`: «R² подгонки сигмоиды невода меньше» (без значения по умолчанию).
- Для сети R² нет (парабола задаётся методикой), показываем только пробу сети, если она отличается от пробы невода.

**6. Вывод** — одна фраза, собирается по шаблону из колонок 2–5 (без генерации текста моделью), RU/KK.
- Все правила заданы и ни одно не сработало: «Проверки пройдены: уловистость определена данными, невод и сеть
  согласуются, поколения не растут».
- Сработало хотя бы одно: «Есть вопросы: …» — пункты по порядку важности:
  1) «проба за все годы — параметры года взяты из сводной пробы»;
  2) «{p} % запаса — возрасты {возрасты}, где уловистость {невода/сети} на границе»;
  3) «невод даёт в {r} раза больше сети» / «сеть даёт в {r} раза больше невода»;
  4) «{k} из {n} поколений выросли за год (наибольший рост ×{x})»;
  5) «в пробе {n} рыб» / «R² подгонки {r2}».
- Порог хотя бы одного правила не задан: пункты-факты без слов «Есть вопросы» и в конце
  «Пороги не заданы — оценка не выполнена (Конструктор → Правила замечаний)».
- Уровень строки: без цвета / жёлтый («есть вопросы») / зелёный («проверки пройдены»). **Красного нет** — уровни
  опасности не придумываем; при желании их задаст ихтиолог (отдельное решение).
- Цвета — только из `theme.js` (`SIGNAL`), в обеих схемах.

## Часть Б. Остальные идеи (одобрены, делать после части А)

1. **«На чём держится запас» — подробно.** Слайд по виду: доля запаса на границах по годам (линия) и по возрастам
   (столбцы «запас» с отметкой возрастов, где c на границе). Отвечает: сколько запаса задано ограничением, а не данными.
2. **«Проверка поколений» — подробно.** Тепловая карта «год × возраст» окончательного запаса с диагоналями поколений;
   ячейки, где поколение выросло, выделены; щелчок — числа перехода N(j−1, y−1) → N(j, y). Пример: лещ, поколение
   3–4 лет в 2016 г. — 14,2 млн, в 2017 г. (4–5 лет) — 50,9 млн (×3,6). По всем видам Жайсана поколение «растёт»
   в 302 из 738 переходов (≈ 40 %).
3. **«Согласие орудий» по возрастам.** Тепловая карта отношения «невод/сеть» по возрастам и годам; показывает, в каких
   возрастах орудия расходятся. Жайсан: лещ — невод в среднем 3,3× (1,2–11,6×), судак 4,2×, карась 0,4× — вопрос
   математику о заданных c̄ невода/сети для этих видов.
4. **«Паспорт достоверности» вид × год.** Матрица-светофор по всем годам: проба, «проба за все годы», R², упор в
   границы. Пример: сазан 2018–2022 — 0–10 рыб, у всех пяти лет одинаковые j50 = 3,57 и R² = 0,85 (сводная проба);
   лещ 2019 и 2021 — R² 0,42 и 0,40, и именно в эти годы Z = 0,12 и 0,09.
5. **Z по годам как индикатор смертности.** Тренд Z с отметкой ненадёжных лет (по паспорту), сравнение видов
   (судак ≈ 0,7, лещ ≈ 0,31). Сопоставление с естественной смертностью байесовской модели — **только после
   согласования формулы математиком**.
6. **«Кого не видит орудие» — фраза к виду.** Пример: «Невод почти не ловит лещей младше 3 лет: из 100 двухлеток
   попадается одна; оценка этих возрастов — улов, умноженный на 100». Для наблюдателей и планирования съёмок.
7. **«Сильное поколение или артефакт?»** Для поколений, входящих в промысловые возрасты в прогнозе: сила поколения
   рядом с долей его оценки на границах уловистости и проверкой поколений. Пример: лещ 2024 — 2–3 года 47,4 млн и
   3–4 года 58,7 млн, максимум за 10 лет.
8. **Сверка с байесовской моделью.** «Уловистость по методике» рядом с поправкой q модели по возрастам (в прежнем
   приложении лещ q(2–3) ≈ 0,06). **Толкование q и формулу показа утверждает математик.**
9. **Тепловая карта c с переключателем.** Сейчас её строки почти одинаковы. Переключатель: c / отклонение от
   многолетней средней / невод÷сеть (идея 3) / рост поколений (идея 2).

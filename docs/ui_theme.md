# Тема интерфейса «Глубокая вода»

Утверждена заказчиком 20.10.2026 (выбор из трёх вариантов: «Глубокая вода», «Степь и небо», «Графит»).
Тёмная тема отложена. Переменные устроены так, что её можно добавить без переделки компонентов.

## Где задаются цвета

| Файл | Что в нём |
|---|---|
| `frontend/src/assets/app.css` | CSS-переменные `--fs-*` и настройка Element Plus (`--el-*`): шкалы оттенков, рамки, текст, шрифт |
| `frontend/src/theme.js` | те же цвета для JavaScript: палитра ECharts, роли цветов на графиках, статусы карты и шагов запуска, тема ECharts `fishstocke` |
| `frontend/src/theme.test.js` | проверки: `theme.js` совпадает с `app.css`; в компонентах нет прописанных цветов (кроме белого); контраст текста ≥ 4,5:1 (WCAG AA); 10 разных цветов графиков и 4 разных статуса карты |

**Правило:** цвета в компонентах прописывать нельзя. В стилях используются `var(--fs-…)`, в коде графиков и карты —
константы из `theme.js`. Нарушение этого правила ловит тест `npm test`.

## Основные цвета

| Переменная | Значение | Назначение |
|---|---|---|
| `--fs-primary` | `#0E5E6F` | основной: кнопки, ссылки, активные элементы, основная величина на графике |
| `--fs-primary-hover` | `#0B4B59` | наведение, активный пункт меню |
| `--fs-primary-2` | `#14919B` | вторичный бирюзовый: модельные кривые, аватар |
| `--fs-primary-soft` | `#A9D3D6` | фоновые ряды графиков (биомасса запаса, исторический ПДУ) |
| `--fs-accent` | `#F2A541` | янтарь — **только** ПДУ, прогноз, логотип, метка активного пункта меню |
| `--fs-accent-text` | `#9A5B0A` | янтарь для текста (контраст AA) |
| `--fs-nav` | `#0E5E6F` | боковое меню |
| `--fs-bg` / `--fs-card` / `--fs-card-soft` | `#F4F7F8` / `#FFFFFF` / `#F9FBFB` | фон страницы, карточки, заголовки таблиц и плашки |
| `--fs-line` / `--fs-line-soft` | `#DCE5E8` / `#EBF0F2` | рамки, линии сетки |
| `--fs-text` / `--fs-muted` / `--fs-faint` | `#1C2B33` / `#5B6F78` / `#74858D` | текст, пояснения, пропуски данных |
| `--fs-selected` / `--fs-hover` | `#E7EFF1` / `#F0F5F6` | выбранная строка, наведение |
| `--fs-success` / `--fs-warning` / `--fs-danger` | `#1B7A4B` / `#A9650F` / `#C0392B` | состояния (тёмнее стандартных Element Plus — для контраста текста) |

Шкалы Element Plus (`light-3 … light-9`, `dark-2`) рассчитаны по правилу самой библиотеки: смешение с белым на 30–90 %
и с чёрным на 20 %.

## Графики

Палитра рядов (виды рыб, сценарии, орудия лова), по порядку:
`#0E5E6F #E07B39 #3E7CC9 #8E5BA8 #5BA05B #C8486A #6FC2C6 #8C6D46 #3F4A52 #E6C440`.

Различимость проверена расчётом цветового расстояния ΔE (CIECAM02-UCS, библиотека colorspacious). Минимальное
расстояние между любыми двумя цветами — 13 при обычном зрении и не меньше 7 при полной дейтеранопии, протанопии
и тританопии.

Роли цветов (`CHART` в `theme.js`): основная величина — `primary`, модельная кривая — `primary-2`, сопоставляемый
фоновый ряд — `primary-soft`, ПДУ и прогноз — янтарь `#E89A2C`, границы допустимого — `danger`.

## Карта

Смысл цветов утверждён в плане и не менялся: серый `#9AA3AB` — нет данных, синий `#2F6FD1` — есть данные,
зелёный `#2E9E5B` — есть расчёт, оранжевый `#E8862A` — данные новее расчёта. Синий статуса намеренно отличается
от бирюзы интерфейса. Граница Казахстана и контуры в редакторе водоёма — основной цвет.

## Стиль

- Шрифт **Inter 5.2.8** (`@fontsource/inter`, начертания 400/500/600). Шрифт входит в сборку и работает без интернета.
  Кириллица и казахские буквы (ә ғ қ ң ө ұ ү һ і) есть; если Inter не загрузился, используются Segoe UI / Roboto.
- Карточки без теней, рамка 1 px, скругление 8 px, у элементов управления — 6 px. Тень только у всплывающих
  панелей (`--fs-shadow-pop`).
- Заголовки — насыщенность 600 (раньше 620–700). Заголовки таблиц — 12,5 px, приглушённым цветом. Числа одной ширины
  (`tabular-nums`).
- Меню: пункты со скруглением, активный пункт — тёмная заливка и янтарная метка слева. Ширина меню 260 px, в свёрнутом
  виде 64 px (только значки).

## Как добавить тёмную тему (позже)

1. Добавить в `app.css` блок `html.dark { --fs-…: … }` с тёмными значениями и подключить
   `element-plus/theme-chalk/dark/css-vars.css`.
2. В `theme.js` добавить тёмный вариант `CSS` / `ECHARTS_THEME`, регистрировать тему ECharts по текущему режиму.
3. Расширить проверку контраста в `theme.test.js` на тёмные пары.

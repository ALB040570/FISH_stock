# Тема интерфейса «Степь и небо»: светлая и тёмная схемы

Утверждена заказчиком 22.10.2026 (заменила «Глубокую воду» от 20.10): тёмно-синий, небесный и золото — мотив флага РК.
Тёмная схема сделана по просьбе заказчика для пользователя с глаукомой, которому тяжело смотреть на белое.

## Где задаются цвета

| Файл | Что в нём |
|---|---|
| `frontend/src/assets/app.css` | `:root` — светлая схема, `html.dark` — тёмная: переменные `--fs-*` и настройка Element Plus (`--el-*`): шкалы оттенков, фон, текст, рамки, шрифт; правила тёмной схемы, которые не задаются переменными (подложка карты, подсказки Leaflet, полосы прокрутки) |
| `frontend/src/theme.js` | `THEMES.light` / `THEMES.dark`: те же цвета для JavaScript — палитра графиков, роли цветов на графиках, статусы карты и шагов запуска, тепловые карты, замечания; темы ECharts; `setTheme` / `toggleTheme` / `initTheme`. Экспортируемые `CSS`, `CHART`, `MAP` … — реактивные: графики и карта перекрашиваются без перезагрузки |
| `frontend/index.html` | ставит класс `dark` до загрузки приложения — без белой вспышки при открытии |
| `frontend/src/components/ThemeToggle.vue` | кнопка «Тёмная тема / Светлая тема» — в верхней строке и на экране входа |
| `frontend/src/theme.test.js` | для обеих схем: совпадение `theme.js` с `app.css`; контраст текста ≥ 4,5:1 (WCAG AA); 10 разных цветов палитры, заметных на карточке; 4 разных статуса карты; в тёмной — нет чистого чёрного и белого; переключение меняет цвета и класс страницы; в компонентах нет прописанных цветов (кроме белого) |

**Правило:** цвета в компонентах прописывать нельзя. В стилях — `var(--fs-…)`, в коде графиков и карты — значения из
`theme.js`. Текст на основном цвете — `var(--fs-on-primary)` (в тёмной схеме основной цвет светлый, текст на нём тёмный).

## Выбор схемы

Кнопка с луной/солнцем в верхней строке (и на экране входа). Выбор запоминается в браузере; при первом входе
берётся настройка системы (светлая/тёмная). Графики, карта, таблицы перекрашиваются сразу.

## Основные цвета

| Переменная | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--fs-primary` | `#16324F` тёмно-синий | `#5BBCD8` небесный | кнопки, ссылки, активные элементы |
| `--fs-on-primary` | `#FFFFFF` | `#0B1620` | текст на основном цвете |
| `--fs-primary-2` | `#00A3C4` небесный | `#7CCBE2` | линии, значки |
| `--fs-accent` | `#E8B40C` золото | `#F0C548` | **только** ПДУ, прогноз, логотип, метка активного пункта меню |
| `--fs-accent-text` | `#8A6A00` | `#F0C548` | золото для текста |
| `--fs-nav` | `#16324F` | `#0D141C` | боковое меню |
| `--fs-bg` / `--fs-card` | `#F6F7F9` / `#FFFFFF` | `#121A24` / `#18222E` | фон страницы, карточки |
| `--fs-text` / `--fs-muted` | `#1A2230` / `#566275` | `#DDE4EC` / `#A3AFBD` | текст, пояснения |
| `--fs-success` / `--fs-warning` / `--fs-danger` | `#1B7A4B` / `#A9650F` / `#C0392B` | `#55C893` / `#E5A94A` / `#F08174` | состояния |

**Тёмная схема для чувствительных глаз:** фон — тёмно-синий, не чёрный; текст — мягкий светлый `#DDE4EC`,
не чисто белый (меньше засветки); цвета приглушены; подложка OpenStreetMap затемняется фильтром (инверсия
с приглушением), чтобы карта не «светила»; картинки-схемы методики в справке показываются на светлой подложке.
Контраст основного текста 12,5–13,7:1, пояснений 6,7–7,9:1 (требование WCAG AA — 4,5:1).

Шкалы Element Plus (`light-3 … light-9`, `dark-2`) рассчитаны по правилу самой библиотеки: в светлой схеме —
смешение с белым на 30–90 % и с чёрным на 20 %; в тёмной — смешение с фоном страницы и с белым на 20 %.
Подключены переменные тёмной схемы Element Plus (`element-plus/theme-chalk/dark/css-vars.css`) и поверх них — наши.

## Графики

| | Светлая | Тёмная |
|---|---|---|
| Палитра рядов | `#16324F #E69F00 #56B4E9 #009E73 #D55E00 #CC79A7 #0072B2 #8C6D46 #595960 #732E2E` (основа Окабе–Ито) | `#D3DAE2 #F0A23C #62BEEE #2DB78A #F07A3A #DE8DB8 #7A9CF0 #B26B8F #E0D187 #657AE0` |
| Мин. ΔE при обычном зрении / при полной дейтер-, протан-, тританопии | 21,6 / 11,0 | 11,9 / 6,9 |
| Контраст с карточкой | ≥ 2,2 (линии) | ≥ 4,1 |

ΔE — цветовое расстояние CIECAM02-UCS (библиотека colorspacious); палитры подобраны перебором (скрипт в истории
сессии 22.10). Роли (`CHART`): основная величина — тёмно-синий / небесный, модельная кривая — небесный, фоновый ряд —
светло-небесный / `#4F7A9C`, **ПДУ и прогноз — золото**, границы допустимого — `danger`.
Тепловые карты: последовательная шкала в тонах «небо → тёмно-синий», расходящаяся — синий/оранжевый; подписи ячеек —
цветом текста с обводкой цветом карточки (читаются на любой клетке).
Снимок графика (PNG/PDF) выгружается в текущей схеме.

## Карта

Смысл цветов статусов утверждён в плане и не менялся; оттенок «есть данные» — сине-фиолетовый `#5B5BD6`
(тёмная `#8C8CF0`), чтобы не сливаться с небесным цветом интерфейса (решение 22.10). Остальные: серый — нет данных,
зелёный — есть расчёт, оранжевый — данные новее расчёта. Граница Казахстана — основной цвет схемы.

## Стиль

- Шрифт **Inter 5.2.8** (`@fontsource/inter`, 400/500/600), в сборке — работает без интернета; кириллица и казахские буквы.
- Карточки без теней, рамка 1 px, скругление 8 px; тень — только у всплывающих панелей (`--fs-shadow-pop`).
- Заголовки — 600; заголовки таблиц — 12,5 px приглушённым цветом; числа одной ширины (`tabular-nums`).
- Меню: тёмно-синее (в тёмной схеме — почти чёрно-синее), активный пункт — золотая метка слева.

# Инструкция пользователя

> Полное руководство пользователя на русском и казахском — в приложении: раздел **Справка** (выгрузка в Word и PDF).
> Тексты справки — `services/help/app/content`; инструкция по установке — [install.md](install.md). Ниже — краткая памятка.
>
> Кабинеты: **Сбор данных** (исходные данные) → **Расчёт запасов рыб** (расчёты, запуски, параметры водоёмов) → **Мониторинг
> водоёмов** (карта, мониторинг, дашборды); **Моделирование** (структура данных, алгоритмы, порядок расчёта, дашборды, правила
> замечаний) · **Администрирование** (пользователи, журнал, каталог алгоритмов). После входа — страница «Поток данных».
> Подробности — в справке, статья «Вход, интерфейс и язык».

## Ихтиолог: от данных до ПДУ

1. **Водоём.** «Моделирование → Структура данных» → «Водоёмы»: найдите водоём (37 предзаполнены) или добавьте новый — название, тип,
   область, точка (щелчок по карте), по желанию контур (обвести или загрузить GeoJSON/KML).
2. **Данные.** «Расчёт → Исходные данные» → водоём → для каждого типа «Шаблон» → заполнить → «Загрузить». Кнопка
   «Только проверить» показывает ошибки без сохранения. Пустая ячейка — «вид не учитывался», не ноль.
3. **Правка.** Открыть набор → «Правка» → изменить ячейки → «Сохранить новую версию». «Сравнение версий» показывает
   изменённые, добавленные и удалённые строки; любую версию можно восстановить.
4. **Расчёт.** Карта → водоём → «Запустить расчёт» (или «Расчёты → Расчёты»). Если расчёта для водоёма ещё нет —
   «Моделирование → Порядок расчёта» → «Новый расчёт» из шаблона. Задайте параметры
   запуска (например, виды и число выборок байесовской модели, горизонт прогноза, k, фиксированный ПДУ),
   «Проверить готовность» → «Запустить расчёт». Расчёт идёт в очереди; страницу можно закрыть.
5. **Результаты.** «Расчёты → Расчёты» → расчёт → запуск в истории (или «Все запуски»): по каждому шагу — представление (графики), таблицы (поиск, CSV), файлы
   (Excel, NetCDF), журнал, параметры. «Все результаты (zip)», «Отчёт Word/PDF».
6. **Основной запуск.** Проверенный запуск отметьте «Сделать основным» — его показывает мониторинг водоёма.
7. **Мониторинг.** «Мониторинг водоёмов → Мониторинг водоёма» (или карта → водоём → «Мониторинг»): вкладки «Исходные данные», «Уловистость», «Запасы», «ПДУ».
   На вкладке ПДУ видно, из чего сложилась цифра: запас → биомасса → квота НПЦ → ПДУ по возрастам, прогноз по сценариям.

## Математик

- **Параметры водоёмов** («Расчёт запасов рыб») — профили: априорные распределения и варианты формул байесовской модели по видам; для нового водоёма
  скопируйте профиль Жайсана и проверьте значения (научную корректность подтверждает математик).
- **Алгоритмы** («Конструктор») — см. [algorithms.md](algorithms.md).

## Дашборды

Смотреть — «Мониторинг водоёмов» → дашборд. Создать — «Моделирование → Дашборды» → шаблон → «Сделать копию» или «Новый дашборд»: добавить вкладки и виджеты (показатель,
график, столбцы, таблица, текст, особое представление), источник (набор данных, таблица результатов, представление шага),
оси, ряды, агрегирование, фильтр строк, ширина/высота. Доступ — «только мне» или «всем пользователям». Для сравнения
водоёмов отметьте «Водоёмы для сравнения» и в виджете «по всем выбранным водоёмам».

## Администратор

«Администрирование → Пользователи»: создать (временный пароль — пользователь сменит его при первом входе), изменить
(ФИО, e-mail, должность, организация, роль; логин не меняется), блокировка, сброс пароля, убрать фото, удалить
(меню «⋯» строки). После 10 неудачных попыток входа учётная запись блокируется автоматически. Организации —
справочник «Организации» (Моделирование → Структура данных).
Каждый пользователь сам меняет имя, e-mail, должность, организацию, фото и пароль: имя вверху справа → «Мой профиль».
«Журнал действий»: фильтры по датам, пользователю, сервису, действию; выгрузка в Excel; хранение 365 дней.

# Языки интерфейса

Интерфейс — русский (`frontend/src/i18n/ru.js`) и казахский (`frontend/src/i18n/kk.js`), переключатель РУС/ҚАЗ
в шапке и на странице входа; выбор сохраняется в браузере.

**Казахский перевод — черновик разработчика, требует вычитки носителем языка** (ихтиологические термины:
уловистость — аулағыштық, ПДУ — ШРА (шекті рұқсат етілген ауланым), невод — ау, сеть — желі, запас — қор).
Для правки достаточно изменить строки в `kk.js` и пересобрать фронтенд.

На русском остаются: названия и описания из методики, приходящие из расчётов (заголовки таблиц результатов,
статусы подгонки), сообщения проверки данных от сервисов (для основных ошибок есть перевод по коду), данные
пользователей (названия водоёмов и видов берутся из полей `name_kk`/`title_kk` справочников, если заполнены).

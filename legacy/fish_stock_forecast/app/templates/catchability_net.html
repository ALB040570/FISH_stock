Таблица по возрастам для выбранного года
Метод расчёта 
c¹ = max(m0 + 1, argmax Yj)                      — вершина
cj = c⁰ − a1·(j − c¹)²,  2 ≤ j ≤ c¹                  (22)
cj = c⁰ − a2·(j − c¹)²,  c¹ ≤ j ≤ m1
c(2) = c⁰ − a1·(2 − c¹)² = c̄/3
c(m1) = c⁰ − a2·(m1 − c¹)² = 2c̄/3
(1/n)·Σ cj = c̄     →   c⁰ = (c̄ − A1·c̄/3 − A2·2c̄/3)/(1 − A1 − A2)   (23)
c̄/3 ≤ cj ≤ 0,8                                           (24)

j — номер возраста: возраст j означает рыб от j−1 до j лет (j = 2 — возраст 1–2 года, двухлетки). c̄ — заданный средний коэффициент уловистости сети вида. В статье суммирование начинается с j = 1; одногодков в уловах нет, поэтому здесь первый возраст — 1–2 года (j = 2).

σ — доля рыб первого круга (радиус равен пути рыбы за час), попавших в сеть за время стоянки, по модели баланса 12 колец; внутри круга 0 час делится на ⌈V/r0⌉ подшагов (NET_ZONE0_SUBSTEPS). Запас по улову сетью — формула (28) статьи X = Y·S / (π·V²·σ); прежняя формула старого кода X = Y·S / (σ·(V² − r0²)) включается настройкой NET_STOCK_FORMULA = "code".

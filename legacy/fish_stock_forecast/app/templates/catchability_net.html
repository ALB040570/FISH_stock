Таблица по возрастам для выбранного года
Метод расчёта 
c¹ = max(m0 + 1, argmax Yj)                      — вершина
cj = c⁰ − a1·(j − c¹)²,  2 ≤ j ≤ c¹                  (22)
cj = c⁰ − a2·(j − c¹)²,  c¹ ≤ j ≤ m1
c̄ − a1·(2 − c¹)² = 0,1   →   a1 = (c̄ − 0,1)/(2 − c¹)²
c̄ − a2·(m1 − c¹)² = 0,2  →   a2 = (c̄ − 0,2)/(m1 − c¹)²
(1/n)·Σ cj = c̄        →   c⁰ = c̄ + (1/n)·Σ a·(j − c¹)²    (23)
0,1 ≤ cj ≤ 0,8                                           (24)

j — номер возраста: возраст j означает рыб от j−1 до j лет (j = 2 — возраст 1–2 года, двухлетки). c̄ — заданный средний коэффициент уловистости сети вида. В статье суммирование начинается с j = 1; одногодков в уловах нет, поэтому здесь первый возраст — 1–2 года (j = 2).

σ — доля рыб первого круга (радиус равен пути рыбы за час), попавших в сеть за время стоянки, по модели баланса 12 колец. Запас по улову сетью сейчас считается как в старом коде: X = Y·S / (σ·(V² − r0²)), r0 — половина длины сети; формула (28) статьи X = Y·S / (π·V²·σ) включается настройкой NET_STOCK_FORMULA.

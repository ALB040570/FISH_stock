Настройки прогноза

Площадь водоёма задаётся для всех прогнозных лет (пустые ячейки — площадь последнего года). Смертность — доля половозрелых рыб (возрасты от m0), погибающих за год от естественных причин без хищников; форма кривой по возрастам сохраняется из модели. Пустая ячейка — «из истории»: кривая выборки со случайным годовым колебанием. Фиксированный ПДУ по умолчанию равен ПДУ последнего года.

Метод прогноза 
Будущие годы (для каждой из 500 выборок модели):
  s(t)   — кривая смертности выборки; задан уровень L(t) → кривая масштабируется: среднее s по j ≥ m0 = L(t);
           не задан → годовое колебание ~ N(0, σ) из настроек модели («из истории»)
  γ, α   — давление хищников и множитель ёмкости нерестилищ — случайный год истории той же выборки
  K(t)   — ёмкость нерестилищ по площади водоёма года t
  β(t)   — среднее β за 3 предыдущих года (с 4-го прогнозного года — по прогнозным годам)

ПДУ года t по запасу на начало года X(t−1), промысловые возрасты j ≥ m0:
  M_j = −ln((1 − s_j) / (1 + γ_j))                      естественная смертность вместе с хищниками
  F   = k · M̄,   M̄ — средняя M промысловых возрастов, взвешенная по численности
  C_j = F / (F + M_j) · (1 − e^(−(F + M_j))) · X_j(t−1)  уравнение Баранова, штук
  ПДУ = Σ C_j · w_j / 10⁶, т
Фиксированный ПДУ (т) распределяется по возрастам алгоритмом этапа 3 по запасу X(t−1).
Изъятие β·ПДУ вычитается в уравнении (17); численность года t — по уравнениям (16)–(17).

Все сценарии используют одни и те же случайные годы и колебания смертности, поэтому различаются только выловом. Вероятность снижения — доля траекторий, в которых численность в последний год прогноза ниже, чем в последний год истории.

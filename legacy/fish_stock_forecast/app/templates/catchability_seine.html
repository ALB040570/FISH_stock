Метод расчёта

Для каждого вида и года уловистость невода ищется в виде сигмоиды, формула (24) статьи:

cj = b / (1 + exp(−a·(j − j50))),   j = 2 … m1

Улов возраста j пропорционален уловистости и численности, которая убывает с возрастом:

Yj ≈ cj · N0 · exp(−Z·j)   ⇒   ln Yj = K − Z·j + ln σj

Параметры a, j50, Z, K находятся методом наименьших квадратов в логарифмах с весами, равными числу рыб возраста j в пробе (+1). Множитель b по уловам не определяется (сливается с N0), его задаёт условие (25): среднее cj по возрастам 2…m1 равно заданному c̄. Ограничения (26): 0,1 ≤ cj ≤ 0,8; для двухлеток (возраст 1–2 года) нижняя граница снижена до 0,01.

Годовой улов по возрастам — суммарный улов вида неводом за год, распределённый по долям возрастной пробы (как в save_catch_3d.py). Если в пробе меньше 20 рыб, берётся проба вида за все годы; если неводом вид не пойман, форма берётся из пробы.

j50 по правилу статьи: max(m0 + 1, возраст максимального улова) — показан для сравнения.

# FishStocke

Веб-приложение для определения **предельно допустимого улова (ПДУ)** рыб в водоёмах Казахстана.
Для ихтиологов-аналитиков (данные, расчёты, мониторинг) и математиков (модели и алгоритмы).

Методика — статья «Многовидовые когортные математические модели оценки запасов рыбных ресурсов с применением
байесовского вывода» (Габбасов М., Алданов Е., Исбеков К., Мейрамбекова Л., Болатбекова З.). Расчётное ядро
перенесено из приложения заказчика `fish_stock_forecast` **без изменения формул** (`legacy/` — исходные материалы).

## Возможности

- **Карта водоёмов** — 37 водоёмов Казахстана с контурами; цвет — состояние данных и расчётов; переход к мониторингу.
- **Мониторинг водоёма** — исходные данные, уловистость невода и сети, запасы (байесовская модель и оценки по уловам),
  **прозрачный ПДУ** (запас → биомасса → квота → ПДУ по возрастам), прогноз по сценариям.
- **Справочники** — конструктор сущностей и полей; водоёмы (точка и контур на карте, GeoJSON/KML), виды, орудия лова;
  типы наборов данных, по которым строятся Excel-шаблоны и проверяются загрузки.
- **Входные данные** — загрузка Excel по шаблону с понятными ошибками (строка, столбец, причина), правка в браузере,
  неизменяемые версии, сравнение и восстановление версий. Пропуск ≠ ноль.
- **Моделирование алгоритмов** — черновики (Python-код + манифест параметров), проверка, тестовый прогон на данных
  водоёма, сверка с эталонной версией, публикация.
- **Каталог алгоритмов** — опубликованные версии, включение/отключение, код версии. **Профили водоёмов** — параметры,
  зависящие от водоёма (априорные распределения по видам).
- **Расчёты** — цепочка шагов (уловистость невода → сеть и запас → ПДУ НПЦ по возрастам → байесовская модель →
  прогноз и ПДУ), параметры трёх категорий: *неизменяемые* (в версии алгоритма), *водоёма* (профиль), *запуска*.
- **Запуски** — очередь с N воркерами (длительные расчёты не блокируют интерфейс), ход выполнения, журнал, отмена,
  повтор с шага, история; результаты — таблицы, Excel, NetCDF, отчёт Word/PDF; «основной запуск» водоёма для мониторинга.
- **Дашборды** — шаблоны и конструктор (виджеты, источники, фильтры, сравнение водоёмов), доступ личный/общий.
- **Пользователи и журнал действий** — роли администратор, ихтиолог, математик, наблюдатель; блокировка;
  журнал всех действий (1 год, выгрузка в Excel). Интерфейс на русском и казахском.
- **Справка** — руководство пользователя в приложении на русском и казахском (работа с приложением, методика расчёта
  с формулами, установка): поиск, справка по экрану («?»), правка с версиями, выгрузка в Word и PDF.

## Архитектура

```
          браузер (Vue 3)
               │  /            /api/<сервис>/...
         ┌─────┴──────── шлюз (nginx | deploy/devgateway.py) ─────────────────────────────┐
   users  data-model  data-admin  algo-model  algo-admin ── воркеры (fishrunner)   dashboards   help
   :8001    :8002       :8003       :8004        :8005       шаги — отдельные процессы  :8006      :8007
     └──────────────── общий каталог данных /data/<сервис>/... (файлы, версии) ─────────────┘
```

| Сервис | Каталог | Назначение |
|---|---|---|
| users | `services/users` | вход (JWT), пользователи, роли, блокировка, журнал действий |
| data-model | `services/data_model` | моделирование данных: справочники, водоёмы, типы наборов данных |
| data-admin | `services/data_admin` | администрирование входных данных: шаблоны, загрузка, проверка, версии |
| algo-model | `services/algo_model` | моделирование алгоритмов: черновики, тест, сверка, публикация |
| algo-admin | `services/algo_admin` | администрирование алгоритмов: каталог, профили, расчёты, очередь, результаты |
| dashboards | `services/dashboards` | администрирование дашбордов: шаблоны, конструктор, данные виджетов |
| help | `services/help` | справка: статьи RU/KK (`app/content`), поиск, версии, выгрузка Word/PDF |

## Быстрый старт (Docker)

Нужны Docker и Docker Compose. Сервер: от 4 ядер и 8 ГБ памяти (байесовская модель — лучше 8 ядер / 16 ГБ).

```bash
git clone https://github.com/ALB040570/FISH_stocke.git && cd FISH_stocke
cp .env.example .env
# в .env задайте FISH_JWT_SECRET, FISH_SERVICE_TOKEN (длинные случайные строки) и FISH_ADMIN_PASSWORD
docker compose up -d --build
```

Приложение: `http://<сервер>:8080` (порт — `FISH_HTTP_PORT`). Вход — `admin` и пароль из `FISH_ADMIN_PASSWORD`
(если пароль не задан, он создаётся и записывается в том данных: `users/INITIAL_ADMIN_PASSWORD.json`).

Загрузка данных заказчика (все водоёмы из `samples/`: Жайсан, Балхаш, Капчагай, Самарканд) и создание расчётов:

```bash
python3 tools/seed_samples.py --url http://127.0.0.1:8080 --password <пароль admin> --run stock
```

## Запуск без Docker (Windows / macOS / Linux)

Python 3.11+ и Node.js 20+.

```bash
python -m pip install -r requirements-dev.txt
cd frontend && npm ci && npm run build && cd ..
python deploy/run_local.py               # http://127.0.0.1:8080, данные — ./data
```

Переменные окружения те же, что в `.env.example` (например, `set FISH_ADMIN_PASSWORD=...` в Windows).

## Внешний доступ для коллег

Роль **«Наблюдатель»** — только просмотр (карта, мониторинг, дашборды, результаты). Для доступа по HTTPS с доменным
именем: `docker compose -f docker-compose.yml -f docker-compose.public.yml up -d` (см. [docs/deploy.md](docs/deploy.md)).

## Резервное копирование

```bash
./deploy/backup.sh                       # архив тома данных в ./backups (с контрольными суммами)
./deploy/restore.sh backups/fishstocke_YYYYMMDD_HHMMSS.tar.gz
python tools/backup.py create --data ./data --out ./backups   # без Docker
```

## Тесты и сверка расчётов

```bash
python -m pytest                                 # сервисы, права, загрузка, цепочки, сверка этапов 1–3 и 5
python tools/control_bayes.py sazan              # контрольный пример байесовской модели (≈20 мин)
```

Сверка: этапы 1–3 совпадают с исходным кодом заказчика на тех же данных и воспроизводят сохранённые результаты
от 30.09.2026; прогноз совпадает с `fish_stock_forecast` по тем же выборкам; байесовская модель — суммарная численность
в пределах ±5 %, R̂ < 1,05 (`docs/control/`).

## Структура репозитория

```
frontend/            Vue 3: экраны, виджеты, переводы (src/i18n/ru.js, kk.js)
services/<сервис>/   FastAPI-приложение сервиса (app/), тесты (tests/), зависимости
libs/fishcommon/     общая библиотека: хранилище с версиями, JWT и права, журнал, проверка значений
algorithms/          fishcore (ядро методики), packages/ (5 эталонных алгоритмов), fishrunner, executor
legacy/              исходные материалы заказчика без изменений
samples/zhaysan/     данные Жайсана в Excel-шаблонах FishStocke (из legacy/data_catch)
deploy/              Dockerfile, nginx, Caddy, запуск без Docker, резервное копирование
tools/               перенос данных, загрузка, контрольный пример, генерация документации
docs/                требования, план, решения, API, форматы, инструкции, прогресс, приёмка
```

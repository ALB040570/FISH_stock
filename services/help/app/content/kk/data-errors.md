# Жүктеп салудағы қателер және оларды түзету

Файл тексеруден өтпесе, қосымша кесте көрсетеді: **Жол**, **Баған**, **Хабарлама**. Жол нөмірі — Excel-дегідей (1-жол — тақырыптар). Файлды түзетіп, қайта жүктеп салыңыз; тексеруді **Тек тексеру** түймесімен қайталауға болады.

Хабарламалар орыс тілінде шығады; төменде олардың мағынасы берілген.

| Хабарлама | Не істеу керек |
|---|---|
| Файл не читается как Excel (.xlsx) — файл Excel ретінде оқылмайды | файлды «Excel кітабы (.xlsx)» ретінде сақтаңыз; .xls және .csv форматтары қабылданбайды |
| Лист пуст: нет строки заголовков — парақ бос | «Данные» парағының бірінші жолы — баған тақырыптары |
| Столбец «…»: такого столбца нет в типе … — мұндай баған жоқ | тақырыптың жазылуын тексеріңіз; бұл балық түрі болса — түрді «Балық түрлері» анықтамалығына қосыңыз |
| Столбец «…» повторяется — баған қайталанады | қайталанған бағанды жойыңыз |
| Нет обязательного столбца «…» — міндетті баған жоқ | бағанды қосыңыз (тақырыпты үлгіден алыңыз) |
| «…»: обязательное поле не заполнено — міндетті өріс толтырылмаған | ұяшықты толтырыңыз |
| «…»: нужно целое число / нужно число — бүтін сан / сан қажет | ұяшықтан мәтінді, өлшем бірлігін, артық бос орындарды алып тастаңыз |
| «…»: дата должна быть в виде ДД.ММ.ГГГГ — күн КК.АА.ЖЖЖЖ түрінде болуы тиіс | күнді түзетіңіз |
| «…»: значение «…» не из списка — мән тізімнен емес | ашылмалы тізімнен мән таңдаңыз (мысалы, аулау түрі: ғылыми / кәсіптік) |
| «…»: «…» нет в справочнике «…» — анықтамалықта жоқ | аулау құралы (немесе түр) анықтамалықта болуы тиіс; жазба қосыңыз немесе жазылуын түзетіңіз |
| не меньше … / не больше … — кем емес / артық емес | мән рұқсат етілген шектен тыс (мысалы, аулағыштық 0-ден 1-ге дейін) |
| Повтор строки с тем же ключом (…) — сол кілтпен жол қайталанады | жиынтықта сол жылы/жасы/түрі бар жол бұрыннан бар — көшірмесін жойыңыз |
| m0 не может быть больше m1 | жыныстық жетілу жасы ең жоғары жастан үлкен бола алмайды |
| Минимальная плодовитость больше максимальной | мәндердің орнын ауыстырыңыз |

Ескертулер (сары) жүктеп салуға кедергі келтірмейді:

- **m2 больше m1** (m2 m1-ден үлкен) — түрдің барлық жасы жыртқыштарға жем деп есептеледі; мәнді тексеріңіз;
- **Год даты … не совпадает с годом …** — аулау күні мен «Жыл» бағаны әртүрлі жылдарға жатады; жол «Жыл» бағанындағы жылда есептеледі.

# Алғашқы іске қосу және деректерді жүктеу

## Әкімшінің кіруі

Логин `admin`, құпиясөз — `FISH_ADMIN_PASSWORD` ішінен. Құпиясөз берілмеген болса, ол автоматты түрде жасалып, деректер каталогындағы `users/INITIAL_ADMIN_PASSWORD.json` файлына жазылған (Docker-де — `fishdata` томында). Кіргеннен кейін құпиясөзді ауыстырыңыз.

## Не бар

- Анықтамалықтар: 37 су айдыны (және Самарқанд су қоймасы), 17 балық түрі, аулау құралдары (сүзекі, ау), деректер жиынтықтарының 7 түрі.
- Каталог: a–j алгоритмдері (эталондық нұсқалар), әрқайсысында «Әдепкі» параметрлер жиыны («По умолчанию (эталон 22.10.2026)»); k — жоспарлануда.
- Жүйелік дашбордтар: «Су айдынының мониторингі», «Су айдындары мен жылдарды салыстыру».
- Анықтама (осы нұсқаулық).

## Тапсырыс беруші деректерін жүктеу

Жеткізілімде — Excel үлгілеріндегі тапсырыс беруші деректері (`samples/` қалтасы): Жайсан, Балқаш, Қапшағай және Самарқанд су қоймалары. Барлық су айдынын жүктеп, есептеулер құру:

```bash
python3 tools/seed_samples.py --password 'admin-құпиясөзі' --run stock
```

- `--url http://мекенжай:порт` — қосымша `http://127.0.0.1:8080` мекенжайында болмаса;
- `--water-body zhaysan` — тек бір су айдыны;
- `--run stock` — a–h алгоритмдерінің есептеулерін құру және кезекке қою (ауланым бойынша қор және данадағы ҒӨО ШРА), `--run full` — a–j (модельмен және болжаммен, ұзақ), `--run none` — тек a–h есептеулерін құру.

Қайта іске қосу деректерді жаңа нұсқа ретінде жүктейді және есептеулерді қайта құрмайды (барларын кезекке қояды).

Бұрынғы форматтағы деректер (`*_catch_YYYY.py`, `*_fish_prop.py`, `*_npc_assessment.py` файлдары) үлгілерге былай көшіріледі:

```bash
python3 tools/legacy_to_excel.py --src <файлдар қалтасы> --waterbody balkhash --out samples/balkhash
```

«Сүзекі» мен «ау»-дан басқа құралдармен аулаулар және көшірудің басқа ерекшеліктері команда жұмысының соңында шығарылады.

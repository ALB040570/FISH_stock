# Жұмыс тәртібі: деректерден ШРА-ға дейін

Төменде су айдыны үшін әрекеттердің әдеттегі реті берілген. Әр қадам өз мақаласында сипатталған.

1. **Анықтамалықтағы су айдыны.** Су айдынын картадан табыңыз немесе қосыңыз: атауы, түрі, облысы, картадағы нүкте. → [Су айдынын қосу](help:water-body)
2. **Түрлер мен аулау құралдары.** «Балық түрлері» анықтамалығында деректеріңіздегі барлық түр бар екенін тексеріңіз; қажет болса, қосыңыз. → [Анықтамалықтар](help:dictionaries)
3. **Бастапқы деректер.** Excel үлгілері бойынша жеті деректер жиынтығын жүктеп салыңыз: аулаулар бойынша ауланым, жас сынамалары, жас бойынша орташа салмақ, түрлердің биологиялық параметрлері, жылдар бойынша жағдайлар, ҒӨО қор бағасы, ҒӨО ШРА. → [Деректерді жүктеп салу](help:data-upload)
4. **Алгоритмдер есептеулері.** «Балық қорларының есептеулері» кабинетінде каталог алгоритмдерін ретімен іске қосыңыз: a, b (аулағыштық) → c, d (шынайылық) → e, f (құралдар бойынша жылдық қор) → g (орташаланған қор) → h (данадағы ШРА) → i (модель) → j (болжам және ШРА). Оларды бірден кезекке қоюға болады — әрқайсысы өз кірістерін күтеді. Ең оңайы — каталогтағы **Іске қосу** түймесі («Әдепкі» параметрлер). → [Есептеулер](help:calculations), [Алгоритмдер каталогы](help:catalog)
5. **Параметрлер.** Модель (i) үшін су айдыны түрлерінің параметрлер жиынында мәндері болуы керек; өз мәндеріңіз үшін «Әдепкі» негізінде жиын құрыңыз. → [Алгоритм параметрлері](help:profiles)
6. **Нәтижелер.** Есептеу беті — графиктер, кестелер, файлдар, журнал; су айдынының Word/PDF есебі. → [Есептеу нәтижесі және журналы](help:runs)
7. **Негізгі есептеу.** Су айдыны алгоритмінің алғашқы нәтижесі — негізгі; балама есептеуді (басқа параметрлер, кезең) негізгі етуге болады. → [Есептеулер](help:calculations)
8. **Мониторинг.** Су айдынының мониторингі негізгі есептеулерден жиналған: бастапқы деректер, аулағыштық, қорлар, ШРА және болжам. → [Мониторинг](help:monitoring), [ШРА қойындысын қалай оқу керек](help:pdu-reading)

Деректер өзгерсе немесе кіріс қайта есептелсе, есептеулер **ескіреді** (картада — қызғылт сары түс) — **Ескіргендерді қайта есептеу** түймесін басыңыз. Есептеу журналы әр жолы немен есептелгенін сақтайды.

Есептеудің өзі қалай құрылғаны — [Есептеу әдістемесі](help:method-overview) бөлімінде.

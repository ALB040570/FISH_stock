# Талаптар және орнату тәсілдері

## Құрамы

Қосымша — Python (FastAPI) тіліндегі жеті қызмет, есептеу воркерлері, веб-интерфейс (Vue) және шлюз. Барлық деректер бір деректер каталогында (томында) файлдарда сақталады.

| Қызмет | Docker-сіз порт | Мақсаты |
|---|---|---|
| users | 8001 | кіру, пайдаланушылар, рөлдер, әрекеттер журналы |
| data-model | 8002 | анықтамалықтар, су айдындары, деректер жиынтықтарының түрлері |
| data-admin | 8003 | бастапқы деректердің үлгілері, жүктеп салу және нұсқалары |
| algo-model | 8004 | алгоритмдерді модельдеу |
| algo-admin | 8005 | каталог, профильдер, есептеулер, кезек, нәтижелер (және воркерлер) |
| dashboards | 8006 | дашбордтар және мониторинг |
| help | 8007 | анықтама |
| шлюз | 8080 | қосымшаның бірыңғай мекенжайы: интерфейс және `/api/<қызмет>/` |

## Талаптар

- **Сервер (ұсынылады)**: Linux (Ubuntu 22.04 немесе жаңарақ), Docker Compose бар Docker 24+; 4 ядро және 8 ГБ жад — ең аз, 8 ядро және 16 ГБ — ұсынылады (бір түрдің байестік моделі 15 минуттан 2 сағатқа дейін есептеледі); диск 20 ГБ-тан.
- **Тексеруге арналған компьютер** (Windows, macOS, Linux): не Docker Desktop, не Python 3.11–3.13 және Node.js 20+.
- **Интернет** карта төсемі (OpenStreetMap) үшін және сыртқы қолжетімділік кезінде HTTPS сертификатын шығару үшін қажет. Орнату кезінде — Python және Node.js пакеттерін немесе Docker бейнелерін жүктеу үшін.
- Пайдаланушылардың **браузері**: Chrome, Edge, Firefox немесе Safari-дің өзекті нұсқалары.

## Тәсілдер

1. **Docker** — сервер үшін негізгі тәсіл: [Docker-мен орнату](help:install-docker).
2. **Docker-сіз** — талдаушының компьютері немесе тексеру үшін: [Docker-сіз орнату](help:install-local).

Орнатқаннан кейін — [Алғашқы іске қосу және деректерді жүктеу](help:first-start).

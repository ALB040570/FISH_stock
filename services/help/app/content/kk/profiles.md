# Су айдындарының параметрлері (байестік модель профильдері)

**Су айдынының профилі** — нақты су айдыны үшін әр түр бойынша бөлек іріктелген байестік когорттық модельдің (4-кезең) параметрлері. Профильсіз су айдынының толық есептеуі іске қосылмайды («Нет профиля параметров байесовской модели для этого водоёма»), 1–3 кезеңдер есептеледі.

## Қайда

**Есептеулер → Су айдындарының параметрлері** → «Байестік когорттық модель» алгоритмі → су айдыны. Қойындылар — түрлер; параметрлер топтастырылған:

| Топ | Параметрлер |
|---|---|
| Табиғи өлім | өлім базасы (логқалыпты үлестірімнің μ, σ), шабақтар мен үлкен жастар үшін тіктігі, жылдық ауытқулар, нормалау, шектері және кесу тәсілі |
| Жыртқыштар | шабақтардың жыртқыштардан өлу үлесі $\gamma_{max}$, «жыртқыштарға жем» шекарасы |
| Браконьерлік β | β қиылған қалыпты үлестірімінің μ, σ және шектері, ауланымды шегеру тәсілі, алудың шекті үлесі және шектеу тіктігі, ШРА көбейткіші |
| Толықтыру | уылдырықтың тіршілік етуі (Beta α, β, масштаб), өнімділік аралықтарының ені, өнімділік ығысуы, кім уылдырық шашады, жылдар бойынша уылдырық шашу орындарының сыйымдылығы |
| Бастапқы қор | σ, ауланым бойынша бағаға қатысты рұқсат етілген шектер, бастапқы қорды қандай деректер бойынша алу |
| Шындыққа ұқсастық және формулалар | санды тегістеу, түр есепке алынбаған аулаулар, шындыққа ұқсастықты қай жастан есептеу, күтілетін қордың төменгі шегі, бақылау шуы, $q$ және аудың $Q_{net}$ аулағыштық түзетулері, шындыққа ұқсастық түрі (дельта-логқалыпты немесе қосымшасы бар), бос аулаулардың параметрлері, бос емес аулаулардың үлестірімі |
| NUTS іріктеуі | тізбекке іріктемелер, баптау қадамдары, тізбектер, target_accept, max_treedepth, тізбектердің басталуы және іздеу нүктелерінің саны, орталықтандырылмаған жылдық әсерлер, seed — іске қосу үшін әдепкі мәндер |

Параметр кілтінің астында ол үлестірімнің қай мәнін беретіні көрсетілген: **математикалық күтім (μ)**, **стандартты ауытқу (σ)**, **төменгі шек** немесе **жоғарғы шек**.

Әр параметр формулаларда нені білдіретіні — [Априорлық үлестірімдер және су айдынының профилі](help:method-priors).

## Жаңа су айдыны үшін профиль

1. Су айдынын таңдаңыз. Профильді екі тәсілмен бастауға болады:
   - **Су айдынынан көшіру** → дайын профилі бар су айдыны (мысалы, Зайсан (Жайсан)) → **Көшіру**;
   - немесе бірден **Түр қосу** — түрлерді бір-бірден.
2. **Түр қосу** — түрлер тізімі: алдымен су айдынының деректерінде бар түрлер (ауланым, жас сынамалары), содан кейін анықтамалықтың басқа түрлері. Жаңа түр белгісі бар әдепкі мәндерді алады:
   - *Жайсан көліндегідей мәндер* — Жайсан профилінде бар түрлер үшін (тыран, көксерке, алабұға, торта, шортан, сазан, мөңке, аққайран);
   - *модельдің жалпы мәндері* — қалған түрлер үшін (ақмарқа, жайын, берш, жыланбас, ақ амур, дөңмаңдай және т.б.).

   Екі жағдайда да мәндер осы су айдынына іріктелмеген — ғылыми дұрыстығын математик растайды.
3. **Түрді алып тастау** — су айдынында жоқ түр үшін (түр қойындысында *су айдынының деректерінде жоқ* белгісі).
4. Түрлер бойынша мәндерді тексеріп, өзгертіңіз, содан кейін түсініктемемен **Сақтау** — профильдің жаңа нұсқасы. Сақталмағанша «Қосу» батырмасының жанында *Өзгерістер сақталмаған* белгісі көрінеді.

Модель тек профильдегі түрлерді есептейді. Су айдынының деректерінде профильде жоқ түр болса, есептеуді тексергенде және іске қосқанда ескерту шығады: «түрлер су айдынының профилінде жоқ, олар есептелмейді».

Іске қосуда профиль нұсқасының нөмірі жазылады; профиль өзгергенде бұрынғы іске қосулар өзгермейді.

# Априорлық үлестірімдер және су айдынының профилі

Су айдынының профилі әр түр үшін байестік модельдің белгісіз шамаларының априорлық үлестірімдерін және формула нұсқаларын береді. Түрлер бойынша мәндерді [Су айдындарының параметрлері](help:profiles) бөлімінде қарап, өзгертіңіз; төменде әр параметрдің нені білдіретіні берілген.

Белгілеулер: $\mathrm{LogN}(\mu, \sigma)$ — логқалыпты үлестірім ($\ln x \sim \mathcal{N}(\mu, \sigma)$); $\mathcal{N}_{[a,b]}$ — $[a, b]$ дейін қиылған қалыпты; $\mathrm{U}[a, b]$ — бірқалыпты; $\mathrm{Beta}(\alpha, \beta)$ — бета-үлестірім.

## Табиғи өлім

| Профиль параметрі | Шама | Үлестірім / мағынасы |
|---|---|---|
| Өлім базасы: μ ln, σ | $s_{base}$ | $\mathrm{LogN}(\mu, \sigma)$ — орта жастардың өлімі (қисықтың ең азы); μ = −2,2 жылына ≈ 11 %-ға сәйкес |
| Шабақтар үшін тіктігі: μ ln, σ | $s_{juv}$ | $\mathrm{LogN}$ — кіші жастарға қарай өлім қаншалықты тез өседі |
| Үлкендер үшін тіктігі: μ ln, σ | $s_{age}$ | $\mathrm{LogN}$ — үлкен жастарға қарай өлімнің өсуі |
| Жылдық ауытқулар: σ | $f(t)$ | $\mathcal{N}(0, \sigma)$ — жекелеген жылдағы бүкіл өлім қисығының ығысуы (заморлар, су деңгейі) |
| Ең жоғарғы мәнге нормалау | — | қисықтың теориялық ең жоғарғы мәнінен үлес |
| s-тің төменгі / жоғарғы шегі | — | өлім мәндерін кесу (мысалы, 0 және 0,95) |
| s-ті кесу | — | нормаланған қисық бойынша немесе ең жоғарғы мән бойынша ауыстырумен (мөңке, аққайран) |

## Жыртқыштар

| Параметр | Шама | Мағынасы |
|---|---|---|
| γ_max: шабақтардың жыртқыштардан өлу үлесі | $\gamma_{max}$ | жыртқыштар қысымы $\gamma_j = \gamma_{max}/j$ $m_2$ жасқа дейін, жылдар бойынша тұрақты; түрлердің көбінде 0,3, шортанда 0,2 |
| «Жыртқыштарға жем» шекарасы | $h_j$ | тегіс ($m_2$ маңындағы сигмоида) немесе саты |

## Ауланым және браконьерлік

| Параметр | Шама | Мағынасы |
|---|---|---|
| β: μ, σ, төменгі және жоғарғы шек | $\beta(t)$ | әр жыл үшін $\mathcal{N}_{[a,b]}(\mu, \sigma)$ — нақты ауланымның ШРА-ға қатынасы (1 — ауланым ШРА-ға тең; 1-ден көп — есепке алынбаған ауланым, 1-ден аз — толық ауланбау). Әдепкі бойынша $\mathcal{N}_{[0{,}9;\ 1{,}4]}(1;\ 0{,}06)$, тыранда жоғарғы шек 1,3, алабұғада $\mathcal{N}_{[0{,}7;\ 1{,}4]}(1;\ 0{,}2)$ |
| Ауланымды шегеру | — | алуды аман қалғандардың үлесімен тегіс шектеу (барлық түрде); салыстыру үшін — тегіс (tanh), «1 балықтан кем емес», «ауланым үлесі ≤ 0,95» — [4-кезеңді](help:method-bayes) қараңыз |
| Алу аман қалғандардың үлесінен аспайды | — | алу шегі, әдепкі бойынша 0,95 |
| Алу шектеуінің тіктігі | $k$ | әдепкі бойынша 50: неғұрлым көп болса, шектеу дәл минимумға соғұрлым жақын |
| ШРА көбейткіші | — | шегерер алдында жас бойынша ШРА-ны көбейтеді (сезімталдықты тексеру үшін) |

## Толықтыру

| Параметр | Шама | Мағынасы |
|---|---|---|
| Уылдырықтың тіршілік етуі: Beta α, β, масштаб | $e_0 = k_e \cdot \mathrm{Beta}(\alpha, \beta)$ | дернәсілге дейін тірі қалатын уылдырық үлесі; $k_e$ — масштаб |
| m0 / m1 жасындағы өнімділік: аралық ені | $\theta(m_0) \sim \mathrm{U}[\theta_{min},\ \theta_{min} + w (\theta_{max} - \theta_{min})]$, $\theta(m_1) \sim \mathrm{U}[\theta_{max} - w(\theta_{max} - \theta_{min}),\ \theta_{max}]$ | жетілу жасындағы және ең жоғары жастағы бір аналыққа уылдырық |
| Өнімділік ығысуы, өнімділік 0-ден кем емес | — | өнімділіктің жасқа сызықтық тәуелділігінің пішіні |
| Кім уылдырық шашады | — | жыныстық жетілгендер үлесі бойынша барлық жастар немесе аналықтар үлесі 0,5 болатын 2-ден бастап жастар (шортан) |
| Жылдар бойынша сыйымдылық: σ | $\alpha(t) \sim \mathrm{LogN}(0, \sigma)$ | уылдырық шашу орындары сыйымдылығының жылдық өзгергіштігі |
| Шабақтарды сыйымдылықпен шектеу | — | 100 000 масштабымен немесе масштабсыз (торта) |

## Бастапқы қор

| Параметр | Мағынасы |
|---|---|
| Бастапқы қор: σ | $X_j(0) \sim \mathrm{LogN}(\ln \tilde X_j(0), \sigma)$ |
| бағадан кем емес / артық емес × | бірінші жылдың ауланым бойынша бағасына қатысты рұқсат етілген ауқым |
| Деректер бойынша бастапқы қор | түпкілікті қор (ау және сүзекі) немесе тек сүзекі |

## Шындыққа ұқсастық және формулалар

| Параметр | Мағынасы |
|---|---|
| Санды тегістеу (softplus) | қадамнан кейінгі сан оң болып қалады |
| Түр есепке алынбаған аулаулар | алып тастау (2-кезеңдегідей) немесе нөлдік ауланым деп есептеу |
| j жасынан бастап шындыққа ұқсастық | аулаулар бойынша бағалар қай жастан бақылауларға кіреді (2-ден 6-ға дейін); әдепкі бойынша 3, тортада 2, шортанда 4 |
| Күтілетін қордың төменгі шегі | 10 балықтың тегіс немесе қатаң шегі |
| Бақылау шуы: σ HalfNormal | $\sigma_{obs}$ априорлық масштабы (мөңкеде — $\nu$ вариация коэффициентінің); әдепкі бойынша 0,5, мөңкеде 3 |
| q аулағыштық түзетуі: σ | $u_j \sim \mathcal{N}(0, \sigma)$, $q_j = e^{u_j}$ |
| Аудың q_net аулағыштық түзетуі | ау аулаулары үшін $Q_{net}$ түзетуін қосу (сүзекі — тірек құрал) |
| ln q_net: σ | $\ln Q_{net} \sim \mathcal{N}(0, \sigma)$, әдепкі бойынша 1 |
| Аулаулар бойынша бағалардың шындыққа ұқсастығы | дельта-логқалыпты (бос аулаулар — жеке ықтималдық; негізгі нұсқа) немесе қосымшасы бар логқалыпты (тортада) |
| Аулаулар бойынша бағаларға қосымша | әдепкі бойынша 0,1: қосымшасы бар логқалыпты шындыққа ұқсастықта барлық бағаларға қосылады, дельта-логқалыптыда — бос емес аулау бағаларының төменгі шегі |
| Бос аулаулар: c деңгейінің σ | $c_g \sim \mathcal{N}(0, \sigma)$, әдепкі бойынша 2 |
| Бос аулаулар: b көлбеулігінің μ, σ | $b \sim \mathcal{N}(\mu, \sigma)$, әдепкі бойынша 1 және 0,5 |
| Нөлдік емес аулаулар (дельта) | жастар бойынша логқалыпты (негізгі нұсқа), жастар бойынша гамма (мөңкеде) немесе аулаудың жастар бойынша қосындысы үшін логқалыпты |

| Тізбектердің басталуы: іздеу нүктелерінің саны | максимумды іздеуге арналған кездейсоқ нүктелер саны, әдепкі бойынша 8 |

Бұл — іске қосу үшін әдепкі мәндер; есептеуде оларды қайта анықтауға болады.

## Жаңа су айдыны үшін мәндерді қалай іріктеу керек

1. Жайсан профилінің көшірмесінен бастаңыз ([Су айдындарының параметрлері](help:profiles)).
2. Жаңа түрлер үшін мәндерді түрдің биологиясы бойынша беріңіз: ересектердің базалық өлімі, шабақтар үшін тіктігі — шабақтардың өлімі 0,95-ке жақын болатындай, үлкендер үшін тіктігі — $m_1$-ге қарай өлім 1-ге жақындайтындай; жыртқыштардан өлу үлесі $\gamma_{max}$ — су айдынындағы жыртқыштардың үлесі бойынша.
3. Есептеуді іске қосып, диагностиканы тексеріңіз ([Нәтижені қалай тексеру керек](help:method-diagnostics)): жинақталу, ауланым бойынша бағалармен келісу, параметрлердің шындыққа ұқсастығы.
4. Профильді түсініктемемен сақтаңыз — профильдің әр нұсқасы іске қосуларда тіркеледі.

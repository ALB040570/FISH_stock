# Жиі кездесетін мәселелер

| Мәселе | Не істеу керек |
|---|---|
| Бет ашылмайды | қосымша іске қосылғанын (`docker compose ps` немесе `run_local.py` терезесі) және мекенжай/портты тексеріңіз |
| «Қызмет уақытша қолжетімсіз» | қызметтердің бірі іске қосылмаған немесе қайта іске қосылуда; бір минут күтіңіз; Docker-де — `docker compose logs <қызмет>` |
| «Логин немесе құпиясөз қате» | пернетақта тілін тексеріңіз; қатарынан 10 қатеден кейін тіркелгі бұғатталады — әкімшіге |
| Әкімшінің құпиясөзі ұмытылды | басқа әкімші құпиясөзді қалпына келтіреді; әкімші біреу болса — сақтық көшірмеден қалпына келтіріңіз немесе әзірлеушіге хабарласыңыз |
| Port 8080 is already in use / мекенжай бос емес | басқа портта іске қосыңыз: `.env` ішінде `FISH_HTTP_PORT=9000` немесе `run_local.py --port 9000` |
| Карта төсемсіз | OpenStreetMap-қа интернет қолжетімділігі жоқ; су айдындарының контурлары бәрібір көрінеді |
| Есептеу ұзақ «кезекте» | барлық воркер бос емес; `FISH_WORKERS` көбейтіңіз (ядролар мен жад жетсе) немесе аяқталуын күтіңіз |
| Байестік модель өте ұзақ есептеледі | серверде C++ компиляторы (`g++`) жоқ — Docker бейнесінде ол бар; Docker-сіз `g++` / `xcode-select --install` орнатыңыз |
| «Нет профиля параметров байесовской модели» қатесі | су айдынының профилін жасаңыз ([Есептеулер → Су айдындарының параметрлері](help:profiles)) немесе 1–3 кезеңдерді іске қосыңыз |
| Есептеу қадамының қатесі | іске қосуды ашыңыз → қадам → **Журнал**; [Іске қосулар және нәтижелер](help:runs) мақаласын қараңыз |
| Excel жүктеп салудағы қателер | [Жүктеп салудағы қателер](help:data-errors) |
| Docker: бейнелерді жүктеу қатесі (403, timeout) | Docker Hub-қа қолжетімділік жоқ; желіні/проксиді тексеріңіз немесе [Docker-сіз орнатуды](help:install-local) пайдаланыңыз |

Мәселе шешілмесе, қате мәтінін (немесе экран суретін) және қызмет журналын сақтап, әзірлеушіге беріңіз.

# Түсіру: Excel, NetCDF, Word/PDF есебі

| Не | Қайда | Формат |
|---|---|---|
| Бастапқы деректер жиынтығы (кез келген нұсқа) | Деректер жинау → Бастапқы деректер → жиынтық → **Excel** | үлгі форматындағы .xlsx |
| Жүктеп салудың бастапқы файлы | Деректер жинау → Бастапқы деректер → жиынтық → **Бастапқы файл** | жүктеп салынған файл |
| Қадамның нәтиже кестесі | Іске қосу → қадам → **Кестелер** → **CSV** | .csv |
| Қадам файлдары | Іске қосу → қадам → **Файлдар** | Excel, NetCDF (.nc), CSV |
| Іске қосудың барлық нәтижелері | Іске қосу → **Барлық нәтижелер (zip)** | .zip: іске қосу туралы мәліметтер (run.json), барлық қадамдардың файлдары мен журналдары |
| Іске қосу бойынша есеп | Іске қосу → **Word есебі** / **PDF есебі** | .docx / .pdf |
| Әрекеттер журналы | Әрекеттер журналы → **Excel-ге экспорттау** | .xlsx (тек әкімші) |
| Пайдаланушы нұсқаулығы | Анықтама → **Нұсқаулықты жүктеп алу** | .docx / .pdf |

## NetCDF

.nc файлдарында осьтердің белгілері бар «жыл × түр × жас» үш өлшемді массивтер (аулағыштық, қор, дана түріндегі ШРА) бар — оларды Python (xarray), R, Panoply, QGIS ашады. Айнымалылардың атаулары тапсырыс берушінің бұрынғы файлдарындағымен бірдей.

## Есеп

Іске қосу бойынша есеп нәтижелерден автоматты түрде жиналады: есептеу және нұсқалар туралы мәліметтер, түрлер бойынша ШРА, қор, жас бойынша ҒӨО ШРА, модель диагностикасы. Толық есеп үшін 1–5 кезеңдердің іске қосуы қажет; 1–3 кезеңдердің іске қосуы үшін болжам бөлімдері бос болады.

# Түсіру: Excel, NetCDF, Word/PDF есебі

| Не | Қайда | Формат |
|---|---|---|
| Бастапқы деректер жиынтығы (кез келген нұсқа) | Деректерді енгізу → Бастапқы деректер → жиынтық → **Excel** | үлгі форматындағы .xlsx |
| Жүктеп салудың бастапқы файлы | Деректерді енгізу → Бастапқы деректер → жиынтық → **Бастапқы файл** | жүктеп салынған файл |
| Есептеу нәтижесінің кестесі | Есептеу → **Кестелер** → **CSV** | .csv |
| Есептеу файлдары | Есептеу → **Файлдар** | Excel, NetCDF (.nc), CSV |
| Есептеу нәтижесі | Есептеу → **Жүктеп алу** → **Нәтиже (zip)** | .zip: есептеу туралы мәліметтер (calc.json), есептеу журналы (journal.json), файлдар және орындау хаттамасы |
| Су айдыны есебі | Есептеу → **Жүктеп алу** → **Су айдыны есебі Word / PDF** | .docx / .pdf — су айдынының негізгі есептеулері бойынша |
| Әрекеттер журналы | Әрекеттер журналы → **Excel-ге экспорттау** | .xlsx (тек әкімші) |
| Пайдаланушы нұсқаулығы | Анықтама → **Нұсқаулықты жүктеп алу** | .docx / .pdf |

## NetCDF

.nc файлдарында осьтердің белгілері бар «жыл × түр × жас» үш өлшемді массивтер (аулағыштық, қор, дана түріндегі ШРА) бар — оларды Python (xarray), R, Panoply, QGIS ашады. Айнымалылардың атаулары тапсырыс берушінің бұрынғы файлдарындағымен бірдей.

## Есеп

Су айдыны есебі негізгі есептеулерден автоматты түрде жиналады: есептеулер туралы мәліметтер (алгоритм, нұсқа, параметрлер, кезең, ескірген бе), түрлер бойынша ШРА, дана мен тоннадағы қор, жас бойынша ҒӨО ШРА, модель диагностикасы. Модель (i) мен болжамның (j) негізгі есептеулері болмаса, тиісті бөлімдер бос болады.

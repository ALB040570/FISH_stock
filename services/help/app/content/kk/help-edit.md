# Анықтаманы түзету

Анықтаманы әкімші мен математик түзете алады. Қалған рөлдер оны оқиды және Word пен PDF форматында түсіреді.

## Мақаланы өзгерту

1. Мақаланы ашыңыз → **Өзгерту**.
2. **РУС** немесе **ҚАЗ** тілін таңдаңыз — әр мақаланың екі мәтіні бар.
3. Мәтінді сол жақта түзетіңіз, оң жақта — алдын ала қарау.
4. Түсініктеме жазыңыз → **Сақтау**. Әр сақтау — жаңа нұсқа; **Нұсқалар** тарихты көрсетеді, кез келген нұсқаны ашып, **қалпына келтіруге** болады.

Мақаланың бірінші жолы — тақырып: `# Атауы`.

## Белгілеу (Markdown)

| Не | Қалай жазу |
|---|---|
| бөлім тақырыбы | `## Бөлім`, `### Бөлімше` |
| жуан, курсив | `**жуан**`, `*курсив*` |
| тізім | `- тармақ` немесе `1. тармақ` |
| кесте | `\| A \| B \|` түріндегі жолдар, екінші жол `\|---\|---\|` |
| анықтама мақаласына сілтеме | `[мәтін](help:мақала-коды)`, мысалы `[Есептеулер](help:calculations)` |
| ішкі мәтін | `>` белгісінен басталатын жол |
| жолдағы формула | `$X_{ij}(t)$` |
| бөлек жолдағы формула | `$$ … $$` (LaTeX ішкі жиыны: `\frac` бөлшектері, `\sum` қосындылары, индекстер, грек әріптері) |
| код, команда | `` `команда` `` немесе ```` ``` ```` жолдарының арасындағы блок |

## Суреттер және экран суреттері

**Сурет қою** → 10 МБ-қа дейінгі PNG, JPEG, GIF немесе WebP файлы → мәтінге `![белгі](help-image:…)` жолы қойылады. Суреттер Word/PDF түсірілімге де түседі. Болашақ экран суреттерінің орындары «[Экран суреті: …]» ішкі мәтіндерімен белгіленген.

## Қосымшадан қойылатындар

Екі қою-жолы оқу және түсіру кезінде автоматты түрде толтырылады:

- `{{params:<алгоритм коды>}}` — алгоритмнің соңғы қосулы нұсқасының параметрлер кестесі (мысалы, `{{params:pdu_by_age}}`);
- `{{example}}` — таңдалған су айдынының сандарымен жас бойынша ШРА бөлу мысалы (мониторингке арналған іске қосудан).

## Қосымшаны жаңарту

Анықтама мәтіндері қосымшамен бірге жеткізіледі. Жаңартқанда ешкім түзетпеген мақалалар өздігінен жаңарады. Мақала қосымшада түзетілген болса, сіздің түзетуіңіз сақталады, ал мақалада ↻ белгісі және **Жаңа нұсқаның мәтінін алу** ұсынысы пайда болады.

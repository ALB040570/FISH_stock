# Қосымшаны жаңарту

Жаңартпас бұрын сақтық көшірме жасаңыз — [Сақтық көшірме](help:backup).

## Docker-мен

```bash
cd FISH_stock
git pull
docker compose up -d --build
```

## Docker-сіз

Қосымшаны тоқтатыңыз (**Ctrl+C**), содан кейін:

```bash
git pull
source .venv/bin/activate
pip install -r requirements-dev.txt
cd frontend && npm ci && npm run build && cd ..
python deploy/run_local.py
```

## Скриптпен орнатылған серверде

```bash
~/fishstock/deploy/server/update.sh --check   # не жаңа
~/fishstock/deploy/server/update.sh           # деректер көшірмесі → жүктеу → қайта жинау → тексеру
```

Жинау сәтсіз болса, бұрынғы нұсқа жұмысын жалғастырады; скриптті қайта іске қосу әрекетті қайталайды.

## Деректермен не болады

- Деректер, есептеулер, пайдаланушылар, журнал сақталады.
- Жеткізілімнің жаңа анықтамалық жазбалары (түрлер, су айдындары) қосылады; сіз өзгерткен немесе жойған жазбаларға тиіспейді.
- Жеткізілімнің жаңа алгоритм нұсқалары каталогта пайда болып, қосылады; «соңғы қосулы» нұсқасы бар есептеулер ескіреді. 25.10.2026 жаңартуы (a–k каталогы, № 70 шешім) бұрынғы іске қосулар мен тізбектерді бір рет жояды — есептеулер жаңадан құрылып, орындалады.
- Дашбордтардың жүйелік үлгілері, егер оларды пайдаланушылар өзгертпесе, жаңарады.
- Анықтама мақалалары, егер оларды қосымшада түзетпесе, жаңарады; түзетілген мақалалар ↻ белгісін алады ([Анықтаманы түзету](help:help-edit)).

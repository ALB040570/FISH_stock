# Анықтамалықтар: су айдындары, түрлер, аулау құралдары мен орындары

**Конструктор → Деректер құрылымы** (анықтамалықтар) бөлімінде деректердің *қандай болатыны* сақталады: су айдындарының, түрлердің, аулау құралдары мен орындарының тізбелері және жіктеуіштер, сондай-ақ бастапқы деректер кестелерінің құрылымы. Су айдындарының деректерінің өзі — **Есептеу → Бастапқы деректер** бөлімінде.

Бетте екі қойынды бар:

- **Анықтамалықтар (мәндер)** — «Су айдындары», «Балықтар», «Аулау» бөлімдері бойынша топтастырылған мәндер тізбелері және өзіңіз құрған анықтамалықтар;
- **Деректер жиынтықтарының түрлері** — бастапқы деректер кестелерінің құрылымы ([Деректер жиынтықтарының құрылымы](help:dataset-types) мақаласын қараңыз).

## Жүйелік анықтамалықтар

| Анықтамалық | Не сақтайды | Қалай пайдаланылады |
|---|---|---|
| Су айдындары | код, орысша және қазақша атаулар, су айдынының түрі, типі, салалық мәртебесі, балық шаруашылығын жүргізу түрлері, облыстары, алабы, ауданы, нүкте және контур | карта, барлық бөлімдерде су айдынын таңдау |
| Су айдындарының түрлері | теңіз, көл, өзен, су қоймасы, тоған, бөгет, арна | «Су айдынының түрі» өрісі, картадағы сүзгі |
| Су айдындарының салалық мәртебесі | халықаралық, республикалық, жергілікті маңызы бар су айдыны | «Салалық мәртебесі» өрісі, картадағы сүзгі |
| Су айдындарының типтері | табиғи, жасанды | «Су айдынының типі» өрісі, картадағы сүзгі |
| Балық шаруашылығын жүргізу түрлері | әуесқойлық (спорттық) және кәсіпшілік балық аулау, көлдік-тауарлық және торлы балық өсіру шаруашылығы | су айдынының өрісі (бір немесе бірнеше мән) |
| Облыстар | облыстар және республикалық маңызы бар қалалар (2022 жылғы бөлініс) | су айдынының «Облыстар» өрісі, картадағы сүзгі |
| Аулау орындары | әр су айдынының аулау орындары және олардың басқа жазылулары | ауланымдағы «Аулау орны» бағанын тексеру ([Аулау орындары](help:fishing-places) мақаласын қараңыз) |
| Балық түрлері | код (латынша), атаулар, латынша атауы, тұқымдасы, «жыртқыш» белгісі | Excel үлгілеріндегі түр бағандары, есептеулер |
| Балық тұқымдастары | 16 тұқымдас (бекіре, албырт, тұқы, алабұға тұқымдастары және т.б.) | түрдің «Тұқымдасы» өрісі |
| Балықтың жынысы, Азық қоры | аналық / аталық / ювенильді; зообентос / зоопланктон | болашақ биологиялық талдау деректері үшін; есептеулерде әзірге пайдаланылмайды |
| Аулау құралдары | код, атаулар, құрал түрі (сүзекі — белсенді құрал, аудан әдісі; ау — енжар құрал, баланс әдісі), құрал типі | ауланымдағы «Аулау құралы» бағаны; құрал түрі қор формуласын анықтайды |
| Аулау құралдарының типтері | кәсіпшілік, кәсіпшілікке жатпайтын | «Аулау құралының типі» өрісі |
| Аулау түрлері | ғылыми, кәсіпшілік, спорттық-әуесқойлық аулау | ауланымдағы «Аулау түрі» бағаны |

Жіктеуіш-анықтамалықтардың мәндері ТОФИ «Факторлар» жіктеуішінен алынған. Әр мәннің басқа жүйелермен салыстыруға арналған **ТОФИ коды** өрісі бар (мысалы, `_FV_1002` — көл).

**Басқа жазылуы** өрісі (әр жолға біреуден) аулау түрлері мен аулау орындарында бар: файлдарды жүктеп салғанда мұндай жазылулар қабылданып, анықтамалық жазбасына келтіріледі. Мысалы, ескі файлдарда аулау түрі «научный» деп жазылған — бұл «научный лов» (ғылыми аулау) мәнінің басқа жазылуы.

Жүйелік анықтамалықтар мен олардың жүйелік өрістерін есептеулер пайдаланады: мұндай өрістерді жоюға немесе түрін өзгертуге болмайды. Жазбалар мен жаңа өрістер қосуға болады.

## Жазбалар

Анықтамалықты ашыңыз → **Жаңа жазба** немесе жолдағы **Өзгерту**. Міндетті өрістер белгіленген. Жазба коды — латынша, бос орынсыз; ол файлдар мен есептеулерде пайдаланылады. Жүйелік анықтамалықтар жазбаларының кодын өзгертуге болмайды.

Жазбаны әр сақтау — жаңа нұсқа; жойылған жазбалар тарихта қалады.

## Жаңа балық түрі

Деректеріңізде анықтамалықта жоқ түр болса (жүктеп салғанда «егер бұл балық түрі болса — оны «Балық түрлері» анықтамалығына қосыңыз» қатесі шығады):

1. **Конструктор → Деректер құрылымы** → **Балық түрлері** → **Жаңа жазба**.
2. Латынша код (мысалы, `zherekh`), орысша атауы **Excel бағанының тақырыбындағыдай дәл** (мысалы, «жерех»), қазақша атауы, латынша атауы, тұқымдасы.
3. Сақтап, файлды қайта жүктеп салыңыз.

Анықтамалықтағы «жыртқыш» белгісі — әдепкі мән; есептеуде нақты су айдынының «Түрлердің биологиялық параметрлері» жиынтығындағы белгі пайдаланылады.

## Өз анықтамалығыңыз

**Жаңа анықтамалық** → код, атаулар, сипаттама → **Өріс қосу**: түрі (жол, мәтін, бүтін сан, сан, иә/жоқ, күні, мәндер тізімі, анықтамалыққа сілтеме, анықтамалыққа бірнеше сілтеме, картадағы нүкте, картадағы контур), өлшем бірлігі, міндеттілігі, бірегейлігі, шектері. Өз анықтамалықтарыңызды деректер жиынтықтары түрлерінің өрістерінде («сілтеме» түрі) пайдалануға болады.

# Әріптестерге интернет арқылы қолжетімділік

Басқа ұйымдардың әріптестеріне **Бақылаушы** рөлімен тіркелгілер жасаңыз — олар тек қарай алады ([Рөлдер және құқықтар](help:roles)).

## Тұрақты қолжетімділік: домендік аты бар сервер (HTTPS)

1. Домен үшін (мысалы, `fish.example.kz`) сервердің IP-мекенжайына A DNS-жазбасын жасаңыз; 80 және 443 порттарын ашыңыз.
2. `.env` ішінде `FISH_DOMAIN=fish.example.kz` беріңіз.
3. Іске қосыңыз:

   ```bash
   docker compose -f docker-compose.yml -f docker-compose.public.yml up -d --build
   ```

   HTTPS сертификаты автоматты түрде шығарылады (Caddy, Let's Encrypt).

4. Әріптестерге `https://fish.example.kz` мекенжайын және олардың логиндерін жіберіңіз.

## Басқа сайттар жұмыс істеп тұрған сервер

Серверде жүйелік nginx бар болса және 80, 443 немесе 8080 порттары бос болмаса, FishStock көршілерге ештеңе өзгертпей қатар орнатылады: қосымша тек `127.0.0.1:8095` тыңдайды, ал nginx бөлек мекенжайға арналған бір жаңа файл алады.

1. Орнату (sudo қажет емес; пайдаланушы `docker` тобында болуы керек):

   ```bash
   git clone -b develop https://github.com/ALB040570/FISH_stock.git ~/fishstock
   ~/fishstock/deploy/server/install.sh
   ```

   Алғашқы жинау 15–45 минут алады; байланыс үзілсе тоқтап қалмауы үшін фонда іске қосыңыз: `nohup ~/fishstock/deploy/server/install.sh > ~/fishstock/install.log 2>&1 &`, барысын `tail -f ~/fishstock/install.log` арқылы қараңыз.

   Скрипт құпиялар мен әкімші құпиясөзі бар `.env` файлын жасайды (тек серверде), контейнерлерді жинап іске қосады, деректер үлгілерін жүктейді және күнделікті сақтық көшірмені баптайды (соңғы 7 сақталады). Соңында әкімші құпиясөзін көрсетеді.

2. HTTPS мекенжайы (sudo құпиясөзі қажет):

   ```bash
   ~/fishstock/deploy/server/nginx_site.sh
   ```

   Әдепкі мекенжай — `fishstock.<IP сызықшалармен>.sslip.io`: ол серверге өзі нұсқайды, домен мен DNS қажет емес. Өз домені: `nginx_site.sh fish.example.kz`. nginx қайта жүктелмес бұрын баптау тексеріледі; қате болса, FishStock файлы алынып тасталады және nginx қайта жүктелмейді. Сертификатты Let's Encrypt (certbot) береді.

3. Жаңарту — команда бойынша: [Қосымшаны жаңарту](help:update).

Порт пен воркерлер саны алғаш орнатқанда өзгертіледі: `FISH_PORT=8096 FISH_WORKERS=2 ~/fishstock/deploy/server/install.sh`.

## Компьютерден уақытша қолжетімділік

Қосымша компьютеріңізде іске қосылған болса, уақытша сілтемені Cloudflare Tunnel береді:

```bash
brew install cloudflared            # macOS; Windows және Linux үшін — Cloudflare сайтынан
cloudflared tunnel --url http://localhost:8080
```

Команда `https://….trycloudflare.com` түріндегі мекенжай береді. Ол компьютер қосулы және команда терезесі ашық тұрғанда жұмыс істейді; келесі іске қосқанда мекенжай басқа болады.

> Сыртқы пайдаланушыларға тек «Бақылаушы» рөлін беріңіз және жұмыстан кейін берілген құпиясөздерді ауыстырыңыз.

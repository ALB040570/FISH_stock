# Параметры алгоритмов

**Параметры алгоритма** — именованный набор значений **всех** параметров одного алгоритма: границы уловистости, края параболы сети, число сетей одной ячеи, способ годового запаса, способ объединения невода и сети, настройки распределения ПДУ, априорные распределения модели по видам, настройки прогноза и т. п. Наборы **общие** — к водоёму не привязаны; в расчёте выбирают любой набор этого алгоритма.

## Где

**Расчёты запасов рыб → Параметры алгоритмов** → алгоритм. Слева — наборы алгоритма (★ — «По умолчанию», число расчётов, которые его используют), справа — значения выбранного набора, выбор версии, список расчётов набора.

## «По умолчанию» и свои наборы

- У каждого алгоритма есть набор **«По умолчанию (эталон 22.10.2026)»** — значения методики и расчётов заказчика для оз. Жайсан. Он не меняется.
- **Создать на основе** — копия выбранного набора с новым названием. Измените значения и **Сохраните новую версию** с комментарием (что и почему — например, при несходимости модели). Значения, отличные от «По умолчанию», выделены, рядом — значение по умолчанию.
- Каждое сохранение — **новая версия** набора; прежние версии видны в списке версий (только просмотр).
- Расчёт ссылается на набор **и его версию**. Если у набора появилась новая версия, на странице расчёта есть подсказка; чтобы взять её, измените расчёт (поле «Версия набора»).
- Набор, который используется в расчётах, не удаляется.

## Модель (алгоритм i): значения по видам

Для математической модели значения задаются **по видам** (вкладки видов), параметры сгруппированы: естественная смертность, хищники, браконьерство β, пополнение, начальный запас, правдоподобие и формулы, выборка NUTS. Под ключом параметра указано, какое значение распределения он задаёт: **математическое ожидание (μ)**, **стандартное отклонение (σ)**, **нижняя** или **верхняя граница**. Что означает каждый параметр — [Априорные распределения](help:method-priors).

- **Добавить вид** — вид справочника получает значения: для видов оз. Жайсан — как в эталоне, для остальных — общие значения модели. Научную корректность подтверждает математик.
- **Убрать вид** — вид не будет рассчитываться моделью.
- Какие виды считать, выбирается в самом расчёте (пусто — все виды набора, которые есть в данных). Если вид есть в данных, но нет в наборе, расчёт предупреждает об этом.

Профили модели водоёмов из прежней версии приложения перенесены в наборы с названием водоёма со всеми правками.

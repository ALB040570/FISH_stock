# Параметры водоёмов (профили байесовской модели)

**Профиль водоёма** — параметры байесовской когортной модели (этап 4), подобранные для конкретного водоёма, отдельно по каждому виду. Без профиля полный расчёт водоёма не запускается («Нет профиля параметров байесовской модели для этого водоёма»), этапы 1–3 считаются.

## Где

**Управление → Параметры водоёмов** → алгоритм «Байесовская когортная модель» → водоём. Вкладки — виды; параметры сгруппированы:

| Группа | Параметры |
|---|---|
| Естественная смертность | база смертности (μ, σ логнормального распределения), крутизна для молоди и для старших возрастов, годовые колебания, нормировка, границы и способ обрезки |
| Хищники | база давления хищников (μ, σ), максимальная доля гибели от хищников, граница «корм хищников» |
| Браконьерство β | μ, σ и границы усечённого нормального распределения β, способ вычитания вылова, множитель ПДУ |
| Пополнение | выживаемость икры (Beta α, β, масштаб), ширина интервалов плодовитости, сдвиг плодовитости, кто нерестится, ёмкость нерестилищ по годам |
| Начальный запас | σ, допустимые границы относительно оценки по уловам, по каким данным брать начальный запас |
| Правдоподобие и формулы | сглаживание численности, ловы без учёта вида, с какого возраста считать правдоподобие, нижняя граница ожидаемого запаса, шум наблюдений |
| Параметры выборки | выборок на цепь, шагов настройки, цепей, target_accept, max_treedepth, seed — значения по умолчанию для запуска |

Под ключом параметра указано, какое значение распределения он задаёт: **математическое ожидание (μ)**, **стандартное отклонение (σ)**, **нижняя граница** или **верхняя граница**.

Что означает каждый параметр в формулах — [Априорные распределения и профиль водоёма](help:method-priors).

## Профиль для нового водоёма

1. Выберите новый водоём → **Скопировать из водоёма** → Зайсан (Жайсан) → **Копировать**.
2. Проверьте и измените значения по видам. Значения Жайсана подобраны под Жайсан — научную корректность для другого водоёма подтверждает математик.
3. Для видов, которых нет в профиле Жайсана (например, жерех, сом, берш, змееголов, белый амур, толстолобик), значения нужно задать заново.
4. **Сохранить** с комментарием — новая версия профиля.

В запуске записывается номер версии профиля; при изменении профиля прежние запуски не меняются.

# Параметры водоёмов (профили байесовской модели)

**Профиль водоёма** — параметры байесовской когортной модели (этап 4), подобранные для конкретного водоёма, отдельно по каждому виду. Без профиля полный расчёт водоёма не запускается («Нет профиля параметров байесовской модели для этого водоёма»), этапы 1–3 считаются.

## Где

**Расчёт запасов рыб → Параметры водоёмов** → алгоритм «Байесовская когортная модель» → водоём. Вкладки — виды; параметры сгруппированы:

| Группа | Параметры |
|---|---|
| Естественная смертность | база смертности (μ, σ логнормального распределения), крутизна для молоди и для старших возрастов, годовые колебания, нормировка, границы и способ обрезки |
| Хищники | доля гибели от хищников у сеголеток $\gamma_{max}$, граница «корм хищников» |
| Браконьерство β | μ, σ и границы усечённого нормального распределения β, способ вычитания вылова, предельная доля изъятия и крутизна ограничения, множитель ПДУ |
| Пополнение | выживаемость икры (Beta α, β, масштаб), ширина интервалов плодовитости, сдвиг плодовитости, кто нерестится, ёмкость нерестилищ по годам |
| Начальный запас | σ, допустимые границы относительно оценки по уловам, по каким данным брать начальный запас |
| Правдоподобие и формулы | сглаживание численности, ловы без учёта вида, с какого возраста считать правдоподобие, нижняя граница ожидаемого запаса, шум наблюдений, поправки уловистости $q$ и сети $Q_{net}$, вид правдоподобия (дельта-логнормальное или с добавкой), параметры пустых ловов, распределение непустых ловов |
| Выборка NUTS | выборок на цепь, шагов настройки, цепей, target_accept, max_treedepth, старт цепей и число точек поиска, нецентрированные годовые эффекты, seed — значения по умолчанию для запуска |

Под ключом параметра указано, какое значение распределения он задаёт: **математическое ожидание (μ)**, **стандартное отклонение (σ)**, **нижняя граница** или **верхняя граница**.

Что означает каждый параметр в формулах — [Априорные распределения и профиль водоёма](help:method-priors).

## Профиль для нового водоёма

1. Выберите водоём. Профиль можно начать двумя способами:
   - **Скопировать из водоёма** → водоём с готовым профилем (например, Зайсан (Жайсан)) → **Копировать**;
   - или сразу **Добавить вид** — по одному виду.
2. **Добавить вид** — список видов: сначала те, что есть в данных водоёма (уловы, возрастные пробы), затем остальные виды справочника. Новый вид получает значения по умолчанию с пометкой:
   - *значения как для оз. Жайсан* — для видов, которые есть в профиле Жайсана (лещ, судак, окунь, плотва, щука, сазан, карась, язь);
   - *общие значения модели* — для остальных видов (жерех, сом, берш, змееголов, белый амур, толстолобик и др.).

   В обоих случаях значения подобраны не для этого водоёма — научную корректность подтверждает математик.
3. **Убрать вид** — для вида, которого нет в водоёме (пометка *нет в данных водоёма* на вкладке вида).
4. Проверьте и измените значения по видам, затем **Сохранить** с комментарием — новая версия профиля. Пока не сохранено, рядом с кнопкой «Добавить» видна пометка *Изменения не сохранены*.

Модель считает только виды профиля. Если в данных водоёма есть вид, которого нет в профиле, при проверке и запуске расчёта появляется предупреждение: «видов нет в профиле водоёма, они не будут рассчитаны».

В запуске записывается номер версии профиля; при изменении профиля прежние запуски не меняются.

# Расчёты

**Расчёт** — сохранённое описание того, *что и как считать* для водоёма:

- **наборы данных водоёма** (берутся их текущие версии на момент запуска);
- **цепочка шагов** — алгоритмы методики и их версии;
- **параметры запуска** шагов;
- **форматы результатов** (таблицы, Excel, NetCDF, Word, PDF).

Один и тот же расчёт можно запускать много раз; каждый **запуск** сохраняется отдельно (см. [Запуски и результаты](help:runs)).

## Создать расчёт

**Расчёты** → выберите водоём → **Новый расчёт** → шаблон:

| Шаблон | Шаги | Время |
|---|---|---|
| Запас и ПДУ НПЦ по возрастам (этапы 1–3) | уловистость невода → уловистость сети и запас по уловам → ПДУ НПЦ по возрастам | 1–3 минуты |
| Полный расчёт ПДУ (этапы 1–5) | то же + байесовская когортная модель → прогноз и ПДУ | от 15 минут до 2 часов на вид |

С карты: панель водоёма → **Запустить расчёт** открывает расчёты водоёма.

Что делает каждый этап — в разделе [Методика расчёта](help:method-overview).

## Настроить расчёт

На странице расчёта:

- **Название** и **описание**.
- **Шаги**: алгоритм и версия (по умолчанию — *последняя включённая* версия из каталога; можно закрепить конкретную). Шаги можно переставлять, удалять и добавлять (**+ шаг**).
- **Параметры запуска** под каждым шагом. Пустое поле — значение по умолчанию (подсказка в поле). Например:
  - байесовская модель: *Виды* (пусто — все виды с профилем), число выборок, шагов настройки, цепей — пусто, значит из профиля водоёма;
  - прогноз: *Горизонт прогноза, лет*, *Коэффициент k в F = k·M*, *Площадь водоёма по прогнозным годам*, *Естественная смертность половозрелых*, *Фиксированный ПДУ по видам, т*.
- **Форматы результатов**: таблицы, Excel, NetCDF, Word, PDF.
- **Сохранить** — новая версия расчёта (с комментарием).

Параметры бывают трёх категорий — неизменяемые (зашиты в версию алгоритма), зависящие от водоёма (профиль водоёма) и параметры запуска; в расчёте задаются только последние. Подробнее — [Три категории параметров](help:parameters).

## Проверить и запустить

1. **Проверить готовность** — справа появится **План запуска**: версии алгоритмов, версия профиля, какие наборы данных и каких версий будут использованы. Если чего-то не хватает (нет набора данных, нет профиля для байесовской модели, отключена версия алгоритма), будет сообщение «Расчёт нельзя запустить» с причинами.
2. **Запустить расчёт** — запуск встаёт в очередь. Страницу можно закрыть: расчёт идёт на сервере.

## Запустить с шага

Если вы поменяли параметры только последнего шага (например, k в прогнозе), не нужно заново считать байесовскую модель. В блоке **Запуски** выберите **Запустить с шага** — предыдущие шаги будут взяты из последнего выполненного запуска этого расчёта (в результатах они отмечены «взят из запуска»).

> Запуск с шага возможен, только если данные и версии алгоритмов предыдущих шагов не менялись; иначе приложение сообщит, какой шаг выполнен с другой версией, и предложит запустить расчёт целиком.

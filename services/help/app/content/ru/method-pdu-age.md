# Этап 3. ПДУ НПЦ по возрастам

## Простыми словами

ПДУ НПЦ задан в тоннах на вид. Модели (этап 4) нужен вылов в **штуках по возрастам**. Если просто разделить тонны пропорционально биомассе, в штуках получится непропорционально много молодой (лёгкой) рыбы. Поэтому вводится **нагрузка, растущая с возрастом**: старшие возраста вылавливаются сильнее, молодые сохраняются для нереста. Чтобы не выловить возраст целиком, за один шаг из возраста изымается не больше 75 % остатка; нераспределённая часть квоты переходит на следующий шаг и делится между оставшимися возрастами.

## Подробно

Для вида и года (индексы опущены):

- $\tilde X_j$ — окончательный запас возраста $j$ (этап 2, с учётом возрастов, по запасам), шт;
- $w_j$ — средний вес, г; если веса возраста до $m_1$ нет в данных, берётся вес ближайшего младшего возраста (отмечается «вес взят от ближайшего младшего возраста»);
- ловятся только половозрелые: $M_j = 1$ при $m_0 \leq j \leq m_1$, иначе 0;
- $P$ — ПДУ НПЦ, т, переводится в граммы (× 10⁶); накопленный вылов $A_j = 0$.

**Итерация** $k = 1, 2, \ldots$:

$$X^{(k)}_{j} = \tilde X_j - A_j$$

$$B_j = X^{(k)}_{j}\, w_j\, M_j, \qquad \tilde B_j = B_j\, \frac{j}{m_1}, \qquad \mu_j = \frac{\tilde B_j}{\sum_{j} \tilde B_j}$$

$$\Delta A_j = \min\left(\frac{P\, \mu_j}{w_j},\ 0{,}75\, X^{(k)}_{j}\right)$$

$$A_j \leftarrow A_j + \Delta A_j, \qquad P \leftarrow \max\left(P - \sum_{j} \Delta A_j\, w_j,\ 0\right)$$

Итерации продолжаются, пока квота не исчерпана (остаток меньше 1 г), есть свободный запас (взвешенная биомасса больше 1 г) и не достигнут предел числа итераций. Если ограничение 75 % сработало, недобор квоты по этому возрасту переходит на следующую итерацию и распределяется между остальными возрастами.

Если запаса не хватает, часть квоты остаётся **нераспределённой** — это видно в итогах («не распределено, т») и означает, что ПДУ НПЦ больше, чем позволяет оценка запаса.

## Результаты

- ПДУ по возрастам: штуки, тонны, доля изъятия $A_j / \tilde X_j$, отметка «ограничение 75 %»;
- итоги по видам и годам: ПДУ НПЦ, распределено и не распределено (т), ПДУ в штуках, промысловая биомасса, отношение ПДУ к биомассе, число итераций, причина остановки;
- разбор «запас → биомасса → квота → ПДУ по возрастам» в мониторинге.

# Правка данных, версии и сравнение

Откройте набор: **Входные данные** → водоём → **Открыть** в строке набора. Вверху — версия, комментарий и дата; таблица показывает данные выбранной версии.

## Правка в браузере

1. **Правка** — таблица становится редактируемой.
2. Измените ячейки, **Добавить строку** или удалите строку значком корзины.
3. **Сохранить новую версию** (можно указать комментарий).

Правка проверяется так же, как загрузка из Excel. Если пока вы правили, набор изменил кто-то другой, приложение не сохранит правку и попросит открыть набор заново — так не теряются чужие изменения.

## Версии

- Каждая загрузка и правка — новая неизменяемая версия; прежние версии не удаляются.
- Выберите версию в списке, чтобы посмотреть её данные.
- **Восстановить** (для не текущей версии) создаёт новую версию с теми же данными — история при этом сохраняется.
- **Исходный файл** — скачать файл Excel, из которого была загружена версия.
- **Excel** — выгрузить данные выбранной версии в формате шаблона (их можно поправить и загрузить обратно).

## Сравнение версий

**Сравнение версий** → выберите две версии → **Сравнить**. Показываются добавленные, удалённые и изменённые строки; для изменённых — «было» и «стало» по каждому столбцу.

## Данные и расчёты

Запуск расчёта запоминает, какие версии наборов он использовал. Поэтому старые результаты остаются воспроизводимыми после правки данных. Если данные изменились после последнего расчёта, водоём на карте станет оранжевым — запустите расчёт заново.

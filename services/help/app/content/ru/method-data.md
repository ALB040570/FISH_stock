# Исходные данные и их подготовка

## Что используется

| Набор данных | Обозначение | Где используется |
|---|---|---|
| Уловы по ловам | $Y_{i}(d)$ — улов вида $i$ в лове $d$, шт; орудие (сеть/невод), тип лова, обловленная площадь $s_{area}(d)$ для невода | этапы 1, 2 |
| Возрастные пробы | $Q_{ij}(t)$ — число рыб в пробе | этапы 1, 2 |
| Средний вес по возрастам | $w_{ij}(t)$, г | этапы 3, 5 |
| Биологические параметры видов | $m_{0i}$, $m_{1i}$, $m_{2i}$; крейсерская скорость $v_i$, м/с; средняя уловистость сети $\bar c^{1}_{i}$ и невода $\bar c^{2}_{i}$; хищник; плодовитость мин./макс.; предельная плотность мальков | все этапы |
| Условия по годам | площадь водоёма $S(t)$, км²; длина сети $L(t)$, м; время стоянки сети $T(t)$, ч | этапы 2, 4, 5 |
| Оценка запаса НПЦ | тыс. шт (× 1000) | сравнение на графиках |
| ПДУ НПЦ | $P_{i}(t)$, т | этапы 3, 5 |

Научные и промысловые ловы используются одинаково; тип лова сохраняется для таблиц и графиков.

## Доли возрастов

По возрастной пробе года определяются доли возрастов. К числу рыб каждого возраста до $m_{1i}$ прибавляется единица — отсутствие рыб какого-то возраста в пробе не означает, что их нет в водоёме:

$$\bar Q_{ij}(t) = Q_{ij}(t) + 1, \qquad q_{ij}(t) = \frac{\bar Q_{ij}(t)}{\sum_{j} \bar Q_{ij}(t)}$$

Возрасты старше $m_{1i}$ единицу не получают.

## Улов по возрастам

Улов каждого лова раскладывается по возрастам по долям пробы его года:

$$Y_{ij}(d) = Y_{i}(d)\, q_{ij}(t(d))$$

Годовой улов орудием $k$ (1 — сеть, 2 — невод) — сумма по ловам этого года:

$$Y^{k}_{ij}(t) = \sum_{d \in t} Y^{k}_{ij}(d)$$

## Пропуски

Пустая ячейка вида в лове означает «вид в этом лове не учитывался». Такой лов для этого вида исключается из всех оценок. Ноль — вид учитывали, но не поймали; такой лов участвует в оценках.

## Мало рыб в пробе

Если в пробе вида за год меньше 20 рыб (возрасты 2…$m_1$), кривая уловистости этого года строится по пробе вида **за все годы**; в результатах это отмечено как «проба за все годы (мало рыб в пробе)».

## Площади и единицы

Площадь водоёма переводится в м² (× 10⁶), обловленная площадь невода — из гектаров в м² (× 10⁴), скорость рыбы — из м/с в м/ч (× 3600).

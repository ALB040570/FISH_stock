# Исходные данные и их подготовка

## Что используется

| Набор данных | Обозначение | Где используется |
|---|---|---|
| Уловы по ловам | $Y_{i}(d)$ — улов вида $i$ в лове $d$, шт; орудие (сеть/невод), тип лова, обловленная площадь $s_{area}(d)$ для невода | этапы 1, 2 |
| Рыбы, подвергнутые биологической обработке | $Q_{ij}(t)$ — число рыб, подвергнутых биологической обработке | этапы 1, 2 |
| Средний вес по возрастам | $w_{ij}(t)$, г | этапы 3, 5 |
| Биологические параметры видов | $m_{0i}$, $m_{1i}$, $m_{2i}$; скорость блуждания $v_i$, м/с; средняя уловистость сети $\bar c^{1}_{i}$ и невода $\bar c^{2}_{i}$; хищник; плодовитость мин./макс.; предельная плотность мальков | все этапы |
| Условия по годам | площадь водоёма $S(t)$, км²; длина сети $L(t)$, м; время стоянки сети $T(t)$, ч | этапы 2, 4, 5 |
| Оценка запаса НПЦ | тыс. шт (× 1000) | сравнение на графиках |
| ПДУ НПЦ | $P_{i}(t)$, т | этапы 3, 5 |

Тип лова определяет число сетей одного размера ячеи в лове сетью: в научном лове ставится по две сети на каждую ячею ($n = 2$), в промысловом — одна ($n = 1$). Это учитывается в оценке запаса по сети ([этап 2](help:method-stock)); в остальном научные и промысловые ловы используются одинаково.

## Доли возрастов

По рыбам, подвергнутым биологической обработке в году, определяются доли возрастов. Данные сглаживаются, потому что если рыбы какого-то возраста не попали в биологическую обработку, это не означает, что их нет в водоёме:

1. **Если рыб мало, добавляются соседние годы.** Если у вида за год меньше 30 рыб, подвергнутых биологической обработке, к ним прибавляются данные биологической обработки этого вида за соседние годы $t - 1$ и $t + 1$ (те, что есть в данных).
2. **Одна условная рыба на все данные года.** К возрастным группам до $m_{1i}$ прибавляется в сумме одна условная рыба, поровну: по $1/J_i$ на группу, где $J_i$ — число возрастных групп таблицы 2 не старше $m_{1i}$. Это априорное распределение Дирихле с параметром концентрации $1/J_i$: оно не даёт долям обратиться в ноль, но почти не меняет доли, когда рыб много.

$$\bar Q_{ij}(t) = Q^{*}_{ij}(t) + \frac{1}{J_i}\, \chi(j \leq m_{1i}), \qquad q_{ij}(t) = \frac{\bar Q_{ij}(t)}{\sum_{j} \bar Q_{ij}(t)}$$

где $Q^{*}_{ij}(t) = Q_{ij}(t)$, если рыб, подвергнутых биологической обработке в году, не меньше 30, и $Q_{ij}(t-1) + Q_{ij}(t) + Q_{ij}(t+1)$ — если меньше. Возрасты старше $m_{1i}$ условной рыбы не получают.

Пример расчёта на числах — [Улов по ловам и возрастам](help:method-catch-age).

## Улов по возрастам

Улов каждого лова раскладывается по возрастам по долям возрастов среди рыб, подвергнутых биологической обработке в год лова:

$$Y_{ij}(d) = Y_{i}(d)\, q_{ij}(t(d))$$

Годовой улов орудием $k$ (1 — сеть, 2 — невод) — сумма по ловам этого года:

$$Y^{k}_{ij}(t) = \sum_{d \in t} Y^{k}_{ij}(d)$$

## Пропуски

Пустая ячейка вида в лове означает «вид в этом лове не учитывался». Такой лов для этого вида исключается из всех оценок. Ноль — вид учитывали, но не поймали; такой лов участвует в оценках.

## Мало рыб, подвергнутых биологической обработке

Если у вида за год меньше 20 рыб, подвергнутых биологической обработке (возрасты 2…$m_1$), кривая уловистости этого года (этапы 1 и 2) строится по данным биологической обработки вида **за все годы**; в результатах это отмечено пометкой «за все годы». Это правило касается только формы кривой уловистости; доли возрастов для раскладки уловов считаются по данным года с соседними годами, как описано выше.

## Площади и единицы

Площадь водоёма переводится в м² (× 10⁶), обловленная площадь невода — из гектаров в м² (× 10⁴), скорость рыбы — из м/с в м/ч (× 3600).

# Места лова

Справочник **Места лова** (**Конструктор → Структура данных → Места лова**) хранит места лова отдельно для каждого водоёма. У места есть:

- **водоём** — к какому водоёму относится место;
- **название** на русском и казахском — так место показывается в данных;
- **другие написания** — по одному в строке; так место записано в разных файлах (например, «Тополев мыс» и «м.Топалев» для места «м. Тополев»);
- **точка на карте** и примечание — по желанию.

## Проверка при загрузке уловов

При загрузке или правке набора «Уловы по ловам» значение столбца «Место лова» сверяется с местами **своего** водоёма:

- название места или одно из его других написаний — значение **приводится к названию места**;
- написание, которого нет в справочнике, — **предупреждение** «Места «…» нет в справочнике «Места лова» этого водоёма», загрузка не блокируется, значение сохраняется как есть;
- если у водоёма ещё нет ни одного места — одно предупреждение об этом.

Различия только в регистре, пробелах, точках, дефисах и кавычках не считаются разными написаниями: «м. Волчий» и «м.Волчий» — одно и то же.

Загруженные ранее данные не меняются. Новое написание места начинает действовать при следующей загрузке или правке набора.

## Заполнение из загруженных уловов

Кнопка **Добавить места из загруженных уловов** (математик, администратор) добавляет в справочник все места из текущих версий загруженных уловов, которых в нём ещё нет. Можно сначала выбрать водоём — тогда только его места. Написания, отличающиеся лишь пробелами, точками и дефисами, становятся одним местом: название — самое частое написание, остальные — другие написания.

Разные написания мест Балхаша, Зайсана, Капчагайского и Самаркандского водохранилищ, подтверждённые ихтиологами (например, «м. Тополев», «Тополев мыс», «м.Топалев»; «Карашенгель» и «Карачингиль»), входят в поставку: при заполнении они сразу становятся одним местом. Если справочник был заполнен раньше, администратор применяет их командой `python tools/place_groups.py apply --file services/data_admin/app/seed/place_groups.json`.

## Объединение разных написаний

Разные написания одного места («Коржун», «м. Коржун», «Коржын») объединяет ихтиолог:

- **вручную** — откройте основное место, добавьте в «Другие написания» остальные варианты, лишние записи удалите;
- **по таблице** — администратор формирует таблицу предложений командой `python tools/place_groups.py suggest`, ихтиолог в столбце «Решение» оставляет «объединить» или пишет «отдельно» и при необходимости правит название, затем администратор применяет таблицу: `python tools/place_groups.py apply --file <таблица>`.

Места лова в расчётах не используются: это справочные сведения и единообразие данных.

# Пользователи

Раздел доступен только администратору.

## Создать пользователя

**Новый пользователь** → логин, ФИО, **роль**, временный пароль (не короче 8 символов); при желании — e-mail, должность, организация. При первом входе пользователь сменит пароль на свой.

**Логин после создания не меняется** — по нему ведётся журнал действий. Если логин введён с ошибкой, удалите пользователя и создайте заново (логин удалённого пользователя можно выдать снова).

Роли и права — [Роли и права](help:roles). Для коллег из других организаций — роль **Наблюдатель**.

## Действия

Кнопка **Изменить** и меню **⋯** — в правом столбце каждой строки; он всегда виден, даже если таблица прокручивается вбок.

- **Изменить** — ФИО, e-mail, должность, организация, роль. Исправленное имя пользователь увидит в шапке при следующем открытии приложения; в комментариях показывается актуальное имя. После смены роли пользователю нужно войти заново.
- **⋯ → Заблокировать** — временно закрыть вход: пользователь не сможет войти и продлить текущий сеанс (уже выданный токен действует не дольше 60 минут). **Разблокировать** возвращает доступ.
- **⋯ → Сбросить пароль** — задать новый временный пароль; пользователь сменит его при входе.
- **⋯ → Убрать фото** — если фото пользователя не подходит.
- **⋯ → Удалить** — окончательно: пользователь исчезает из списка и не может войти, его фото удаляется, логин можно выдать заново. Комментарии, расчёты и записи журнала остаются подписанными его именем. Если доступ нужно закрыть временно — блокируйте, а не удаляйте.
- Таблица показывает должность и организацию, **последний вход**; поиск — по имени, логину, должности, организации и роли.

## Организации

Организация выбирается из справочника **«Организации»** (кабинет **Моделирование → Структура данных**). Справочник поставляется пустым — добавьте организации сотрудников: код (латиница, не меняйте после выбора в профилях), название, при желании краткое название — оно показывается в таблице пользователей.

## Профиль пользователя

Каждый пользователь сам меняет своё имя, e-mail, должность, организацию, фото и пароль: имя в правом верхнем углу → **Мой профиль**. Логин и роль меняет только администратор.

После 10 неудачных попыток входа подряд учётная запись блокируется автоматически — разблокируйте её и при необходимости сбросьте пароль.

Последнего администратора нельзя заблокировать, удалить или лишить роли администратора — так приложение не останется без управления.

## Первый администратор

Учётная запись администратора создаётся при первом запуске приложения (логин `admin`, пароль — из настройки `FISH_ADMIN_PASSWORD`; если она не задана, пароль записывается в файл `users/INITIAL_ADMIN_PASSWORD.json` в каталоге данных). См. [Первый запуск](help:first-start).

# Справочники: водоёмы, виды, орудия и места лова

Раздел **Конструктор → Структура данных** (справочники) хранит то, *какими бывают* данные: перечни водоёмов, видов, орудий и мест лова и классификаторы, а также структуру таблиц исходных данных. Сами данные водоёмов — в разделе **Расчёт → Исходные данные**.

На странице две вкладки:

- **Справочники (сущности)** — перечни значений, сгруппированные по разделам «Водоёмы», «Рыбы», «Лов», и справочники, которые вы создадите сами;
- **Типы наборов данных** — структура таблиц исходных данных (см. [Структура наборов данных](help:dataset-types)).

## Системные справочники

| Справочник | Что хранит | Как используется |
|---|---|---|
| Водоёмы | код, названия на русском и казахском, вид водоёма, тип, статус для отрасли, виды ведения рыбного хозяйства, области, бассейн, площадь, точка и контур | карта, выбор водоёма во всех разделах |
| Виды водоёмов | море, озеро, река, водохранилище, пруд, плотина, проток | поле «Вид водоёма», фильтр на карте |
| Статусы водоёмов для отрасли | водоём международного, республиканского, местного значения | поле «Статус для отрасли», фильтр на карте |
| Типы водоёмов | естественный, искусственный | поле «Тип водоёма», фильтр на карте |
| Виды ведения рыбного хозяйства | любительское (спортивное) и промысловое рыболовство, озёрно-товарное и садковое рыбоводное хозяйство | поле водоёма (одно или несколько значений) |
| Области | области и города республиканского значения (деление с 2022 г.) | поле «Области» водоёма, фильтр на карте |
| Места лова | места лова каждого водоёма и их другие написания | проверка столбца «Место лова» в уловах (см. [Места лова](help:fishing-places)) |
| Виды рыб | код (латиницей), названия, латинское название, семейство, признак «хищник» | столбцы видов в шаблонах Excel, расчёты |
| Семейства рыб | 16 семейств (осетровые, лососевые, карповые, окуневые и др.) | поле «Семейство» вида |
| Пол рыбы, Кормовая база | самка / самец / ювенильные; зообентос / зоопланктон | для будущих данных биологического анализа; в расчётах пока не используются |
| Орудия лова | код, названия, вид орудия (невод — активное орудие, метод площадей; сеть — пассивное орудие, балансовый метод), тип орудия | столбец «Орудие лова» в уловах; вид орудия определяет формулу запаса |
| Типы орудий лова | промысловые, непромысловые | поле «Тип орудия лова» |
| Типы вылова | научный, промысловый, спортивно-любительский лов | столбец «Тип лова» в уловах |

Значения справочников-классификаторов взяты из классификатора «Факторы» ТОФИ. У каждого значения есть поле **Код ТОФИ** (например, `_FV_1002` — озеро) для сверки с другими системами.

Поле **Другие написания** (по одному в строке) есть у типов вылова и мест лова: при загрузке файлов такие написания принимаются и приводятся к записи справочника. Например, в старых файлах тип лова записан как «научный» — это другое написание значения «научный лов».

Системные справочники и их системные поля используются расчётами: такие поля нельзя удалить или сменить им тип. Добавлять записи и новые поля можно.

## Записи

Откройте справочник → **Новая запись** или **Изменить** в строке. Обязательные поля отмечены. Код записи — латиницей, без пробелов; он используется в файлах и расчётах. У записей системных справочников код менять нельзя.

Каждое сохранение записи — новая версия; удалённые записи остаются в истории.

## Новый вид рыбы

Если в ваших данных есть вид, которого нет в справочнике (при загрузке появится ошибка «если это вид рыбы — добавьте его в справочник «Виды рыб»»):

1. **Конструктор → Структура данных** → **Виды рыб** → **Новая запись**.
2. Код латиницей (например, `zherekh`), название на русском **точно так, как в заголовке столбца Excel** (например, «жерех»), название на казахском, латинское название, семейство.
3. Сохраните и загрузите файл снова.

Признак «хищник» в справочнике — значение по умолчанию; в расчёте используется признак из набора «Биологические параметры видов» конкретного водоёма.

## Свой справочник

**Новый справочник** → код, названия, описание → **Добавить поле**: тип (строка, текст, целое число, число, да/нет, дата, список значений, ссылка на справочник, несколько ссылок на справочник, точка на карте, контур на карте), единицы, обязательность, уникальность, пределы. Свои справочники можно использовать в полях типов наборов данных (тип «ссылка»).

# Сравнение водоёмов, лет и сценариев

## Страница «Сравнение расчётов»

Кабинет **«Мониторинг» → «Сравнение расчётов»** кладёт на одни графики результаты разных расчётов. Страница доступна администратору, математику и ихтиологу — как и остальные результаты модели.

**Ряд** — это водоём + расчёт + вид, а для прогноза ещё и **k** (F = k·M). Источники рядов:

- **Прогноз и ПДУ (j)** — численность или промысловая биомасса по годам: история модели и прогноз на 2025–2029 гг. при выбранном k; ПДУ по годам прогноза; вероятность снижения запаса; F.
- **Запас по модели (i)** — численность по байесовской модели с интервалом.
- **Запас по уловам (g)** — оценка запаса по уловам выбранным орудием (сеть, невод или их среднее), без интервала.

Как набрать ряды: выберите источник, водоём, расчёт (★ — основной), вид (можно несколько), для прогноза — k (можно несколько) и нажмите **«Добавить ряд»**. Быстрые наборы заменяют текущие ряды:

| Набор | Что получится |
|---|---|
| Вид при всех k | выбранный вид выбранного расчёта прогноза при всех k (по умолчанию 0; 0,25; 0,5; 0,75; 1; 1,25; 1,5; 2) |
| Все виды при одном k | все виды выбранного расчёта при первом выбранном k |
| Вид во всех водоёмах | выбранный вид по основным расчётам всех водоёмов, где он есть |
| Основной и альтернативные | выбранный вид во всех расчётах водоёма с результатом; у прогноза — при k, заданном в каждом расчёте |

В сравнении не больше 12 рядов. Что показывает страница:

- **Численность по годам** (или промысловая биомасса, т — переключатель над графиками). Прогноз каждого ряда продолжает последний год истории модели. Если несколько рядов взяты из одного расчёта прогноза и вида (разные k), история рисуется один раз серой линией. k = 0 — пунктир: промыслового вылова нет. Полосы 95 % включаются флажком **«Интервалы»** (при 1–3 рядах — сразу). Для водоёмов с очень разным запасом удобна **логарифмическая шкала**.
- **ПДУ по годам прогноза, т** — медиана ПДУ по траекториям прогноза.
- **Вероятность снижения запаса** к концу прогноза — доля траекторий, в которых численность в последний год прогноза ниже последнего года истории.
- **Таблица итогов**: численность в последний год истории, F первого года, ПДУ первого года прогноза с 95 % интервалом, численность в конце прогноза с интервалом, риск снижения.

Подписи рядов короткие — в них только то, чем ряды различаются; общее для всех рядов написано строкой над графиками.

**Ссылка.** Набор рядов, показатель, интервалы и шкала хранятся в адресе страницы. Кнопка **«Скопировать ссылку»** копирует его — коллега с правом на результаты откроет то же сравнение.

Страница ничего не пересчитывает: числа берутся из результатов расчётов. Траектории по годам для каждого k есть в расчётах прогноза версии **3.2.0** и новее; у расчётов прежних версий по годам доступны только k = 0 и k самого расчёта — перезапустите прогноз, чтобы появились остальные.

## Водоёмы

Шаблон **«Сравнение водоёмов и лет»**: отметьте **Водоёмы для сравнения** — графики покажут, например, ПДУ НПЦ по водоёмам и окончательный запас по уловам рядами по водоёмам. Сделайте копию шаблона, чтобы добавить свои виджеты.

## Годы

Фильтр строк виджета (`{"year": 2023}` или `"$last_year"`) выбирает год; на линейных графиках по оси X — годы, поэтому видно всю динамику.

## Сценарии прогноза

На вкладке **ПДУ** мониторинга прогноз показан для трёх сценариев: F = k·M, фиксированный ПДУ, без промысла, — а слайды **«Сценарии k»** показывают ПДУ, риск снижения запаса и запас по годам при каждом k из параметра «Сценарии k» расчёта прогноза. Сравнить k разных видов, водоёмов или расчётов — на странице **«Сравнение расчётов»**. Чтобы сравнить другие настройки прогноза (смертность, фиксированный ПДУ), создайте альтернативный расчёт прогноза (j) с другим набором параметров — модель (i) не пересчитывается, она берётся входом.

## Методы оценки запаса

Вкладка **Запасы** мониторинга показывает на одном графике численность по байесовской модели и независимые оценки: по уловам неводом (метод площадей), сетью (балансовый метод) и оценку НПЦ.

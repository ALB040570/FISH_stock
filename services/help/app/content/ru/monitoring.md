# Мониторинг водоёма

Мониторинг — готовая панель по одному водоёму: исходные данные, уловистость орудий лова, запасы и ПДУ. Открыть: карта → водоём → **Мониторинг**, или меню **Мониторинг** → выбрать водоём.

## Какой запуск показан

- Если у водоёма есть **основной запуск** — показан он.
- Иначе — **последний успешный запуск** с пометкой «не отмечен как основной».
- Если расчётов ещё не было — показаны только исходные данные и кнопка **Запустить расчёт**.

Какой запуск показан, видно по метке рядом с выбором водоёма: зелёная точка — основной расчёт, жёлтая — последний расчёт, не основной, серая — расчёта нет. Щелчок по метке открывает название и дату запуска и ссылку на него (или **Запустить расчёт**).

## Вкладки

| Вкладка | Что на ней |
|---|---|
| Исходные данные | разделы «Обзор», «Уловы», «Возрастные пробы», «Средний вес», «Параметры видов и водоёма», «Квоты», «Качество данных» — см. [Исходные данные в мониторинге](help:monitoring-data) |
| Уловистость | раздел «Сводка» — [можно ли верить запасу](help:catchability-trust): по каждому виду проверки уловистости и вывод; разделы «Невод» и «Сеть», слайдами: параметры года с предупреждениями об упоре в границы, улов по возрастам (линейная или логарифмическая шкала), коэффициент уловистости с линиями j50 (вершины) и границ, таблица по возрастам, тепловая карта «годы × возрасты», параметры по годам. При «Все виды» — таблица видов за год (щелчок — все данные по виду). Год — стрелками над слайдами или щелчком по строке тепловой карты и таблицы параметров; формулы — [Уловистость невода](help:method-seine), [Уловистость сети](help:method-net) |
| Запасы | раздел «По уловам», слайдами: запас года (сети, невод, окончательный, оценка НПЦ, невод/сети, число ловов), годовой запас по годам с линией НПЦ, оценки по отдельным ловам, возрастная структура запаса, таблица по годам; при «Все виды» — таблица видов за год (виды не складываются). Переключатели «уловистость по возрастам / средняя по виду» и «по запасам / по улову» и шкала — над слайдом, действуют на все слайды раздела; см. [Запас по уловам](help:method-stock). Раздел «Байесовская модель» (нужен полный расчёт, этапы 1–5), слайдами: итоги модели с предупреждениями о сходимости, численность по годам (медиана, интервалы 50 % и 95 %, оценки по уловам и НПЦ), возрастная структура, пополнение, смертность s, давление хищников γ, β по годам, поправка уловистости q, баланс гибели, параметры модели и диагностика; переключатели «1–2 и старше / с сеголетками» и «оценки как есть / оценки / q»; см. [Байесовская модель](help:method-bayes) |
| ПДУ | два раздела, строго раздельно. **ПДУ НПЦ (официальный)** — квота НПЦ, переведённая в штуки по возрастам: итоги года с предупреждениями, запас и ПДУ по возрастам, доля изъятия, ПДУ и промысловая биомасса по годам, итоги по годам. **ПДУ, рассчитанный в приложении (F = k·M)** — по байесовской модели (нужен полный расчёт): итоги, численность и промысловая биомасса по сценариям (F = k·M, фиксированный ПДУ, без промысла), ПДУ по годам, возрастная структура, ПДУ по возрастам, таблица по годам прогноза; ПДУ НПЦ там показан только для сравнения. См. [Как читать вкладку ПДУ](help:pdu-reading) |

Под строкой с названием — **виды водоёма** в порядке доли в улове. **Все виды** — водоём целиком; щелчок по виду включает режим **«Все данные по виду»**: во всех разделах остаются только виджеты по этому виду, страница открывается на разделе «Обзор», и в их названии стоит название вида. Красная точка у вида — заметное снижение по [светофору видов](help:monitoring-data). При прокрутке шапка сжимается в одну строку: «водоём · вид · раздел · номер слайда».

У каждого виджета есть подзаголовок, выбор вида отображения (график, таблица, плитки), режим «во весь экран», выгрузка в Excel, PDF и PNG и переход к строкам данных; в меню ⋯ над виджетами — **Сравнить годы…** и **Отчёт раздела (PDF)**. Виджеты показываются **слайдами** (по одному, с пояснением и комментариями справа) или **лентой** — переключатель над виджетами. Подробно — [Исходные данные в мониторинге](help:monitoring-data).

## Своя версия мониторинга

Мониторинг — системный шаблон дашборда. **Сделать копию** (меню ⋯ в шапке) создаёт ваш дашборд с тем же содержимым — его можно менять в конструкторе ([Конструктор дашбордов](help:dashboard-builder)). Сам шаблон меняют администратор и математик (**Изменить шаблон**).

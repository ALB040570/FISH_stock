# Мониторинг водоёма

Мониторинг — готовая панель по одному водоёму: исходные данные, уловистость орудий лова, запасы и ПДУ. Открыть: карта → водоём → **Мониторинг**, или меню **Мониторинг** → выбрать водоём.

## Какой запуск показан

- Если у водоёма есть **основной запуск** — показан он.
- Иначе — **последний успешный запуск** с пометкой «не отмечен как основной».
- Если расчётов ещё не было — показаны только исходные данные и кнопка **Запустить расчёт**.

Название запуска вверху — ссылка на его страницу.

## Вкладки

| Вкладка | Что на ней |
|---|---|
| Исходные данные | разделы «Обзор», «Уловы», «Возрастные пробы», «Средний вес», «Параметры видов и водоёма», «Квоты», «Качество данных» — см. [Исходные данные в мониторинге](help:monitoring-data) |
| Уловистость | кривые уловистости невода и сети по возрастам и годам, подгонка по уловам, коэффициенты |
| Запасы | численность по байесовской модели (медиана, интервалы 50 % и 95 %) вместе с оценками по уловам сетью и неводом и оценкой НПЦ; годовой запас по орудиям лова; окончательный запас по возрастам |
| ПДУ | ПДУ по видам, разбор «из чего сложился ПДУ», прогноз по сценариям — см. [Как читать вкладку ПДУ](help:pdu-reading) |

Фильтр **Все виды** вверху сужает графики до одного вида.

У каждого виджета есть подзаголовок, выбор вида отображения (график, таблица, плитки), режим «во весь экран», выгрузка в Excel, PDF и PNG и переход к строкам данных; над виджетами — **Сравнить годы** и **Отчёт раздела (PDF)**. Подробно — [Исходные данные в мониторинге](help:monitoring-data).

## Своя версия мониторинга

Мониторинг — системный шаблон дашборда. **Сделать копию** создаёт ваш дашборд с тем же содержимым — его можно менять в конструкторе ([Конструктор дашбордов](help:dashboard-builder)). Сам шаблон меняют администратор и математик (**Изменить шаблон**).

# Структура наборов данных

**Тип набора данных** описывает таблицу исходных данных: какие в ней столбцы, их типы, единицы, обязательность, пределы, правила проверки. По типу строится шаблон Excel и проверяется загрузка.

Открыть: **Моделирование → Структура данных** → вкладка **Типы наборов данных** → тип.

## Семь системных типов

| Тип | Строка таблицы | Основные столбцы |
|---|---|---|
| Уловы по ловам | один лов (замёт невода или постановка сети) | год, дата, место, орудие лова, описание и размер орудия, обловленная площадь (га; у невода — обязательна и больше нуля, у сети не указывается), тип лова (научный, промысловый, спортивно-любительский лов — справочник «Типы вылова»); место сверяется со справочником «Места лова», улов по видам, шт |
| Рыбы, подвергнутые биологической обработке | год × возраст | число рыб, подвергнутых биологической обработке, по видам, шт |
| Средний вес по возрастам | год × возраст | средний вес по видам, г |
| Биологические параметры видов | вид | m0, m1, m2, скорость блуждания (м/с; файлы с прежним заголовком «Крейсерская скорость» тоже загружаются), средняя уловистость сети и невода, хищник, плодовитость мин./макс., предельная плотность мальков (шт/м²) |
| Условия по годам | год | площадь водоёма (км²), длина сети (м), время стоянки сети (ч) |
| Оценка запаса НПЦ | год | запас по видам, тыс. шт |
| ПДУ НПЦ | год | ПДУ по видам, т |

**Возраст j** во всех таблицах — возрастная группа от j−1 до j лет, как в исходных данных: j = 2 — рыбы от 1 до 2 лет.

## Столбцы видов

Во многих таблицах на каждый вид — свой столбец (зелёный в шаблоне). Заголовок столбца — название вида из справочника «Виды рыб» (русское, казахское, код или латинское). Лишние столбцы видов можно удалить; новый вид сначала добавьте в справочник.

**Пустая ячейка вида — это пропуск** («вид не учитывался в этом лове»), а не ноль. В расчёте такие ловы для этого вида исключаются. Ноль означает «учитывали, но не поймали».

## Ключевые поля и период

- **Ключевые поля** — сочетание, которое не может повторяться (например, год + возраст). Повтор — ошибка загрузки.
- **Поле периода** (обычно год) — по нему работает режим загрузки «заменить годы, которые есть в файле».

## Изменение структуры

Ихтиолог, математик и администратор могут добавлять поля, менять подписи, пределы и подсказки. **Системные поля** используются расчётами — их нельзя удалить или сменить тип. Каждое изменение сохраняется новой версией типа; шаблон Excel после этого строится по новой структуре.

> Новое поле не попадёт в расчёт само по себе: алгоритмы используют только известные им поля. Если поле нужно в методике — это задача математика (новая версия алгоритма).

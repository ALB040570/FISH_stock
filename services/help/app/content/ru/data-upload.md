# Загрузка данных из Excel

Исходные данные водоёма — семь **наборов данных** (по одному на тип). Каждый набор загружается из файла Excel (.xlsx) по шаблону.

## Шаблон

1. **Сбор данных → Исходные данные** → выберите водоём вверху страницы.
2. В строке нужного типа нажмите **Шаблон Excel**.

В шаблоне два листа:

- **Данные** — строка заголовков: обычные столбцы и зелёные столбцы видов. Обязательные столбцы отмечены `*` и выделены цветом; единицы указаны в названии столбца или на листе «Описание». Для столбцов-списков и ссылок на справочники (орудие лова, тип лова) в ячейках есть выпадающий список.
- **Описание** — для каждого столбца тип, единицы, обязательность, допустимые значения и подсказка.

Столбцы видов в шаблоне — виды, которые уже есть в данных водоёма (для нового водоёма — все виды справочника). Лишние столбцы видов удалите, нужные — добавьте, написав в заголовке название вида.

> Удобнее всего править существующий набор так: откройте набор → **Excel** (выгрузка текущих данных в том же формате) → измените файл → загрузите обратно.

## Правила заполнения

- Одна строка — одна запись (один лов, один год × возраст, один вид — в зависимости от типа).
- **Даты** — в формате ДД.ММ.ГГГГ или ячейкой-датой Excel. Год даты должен совпадать со столбцом «Год» (иначе — предупреждение).
- **Числа** — с запятой или точкой; без пробелов и единиц в ячейке.
- **Пустая ячейка вида — пропуск** («вид не учитывался»), **0 — улов (проба) учитывался и равен нулю**. Не заменяйте пропуски нулями.
- Порядок столбцов не важен: столбцы узнаются по заголовкам (русскому или казахскому названию, коду).
- Названия орудий лова, видов, водоёмов — как в справочниках.

## Загрузка

1. **Загрузить Excel** (вверху страницы) или **Загрузить** в строке типа.
2. Выберите тип набора (если не выбран) и файл.
3. Выберите **режим**:
   - **заменить годы, которые есть в файле** — строки годов из файла заменяются, остальные годы остаются (удобно добавлять новый год);
   - **заменить весь набор** — набор полностью заменяется содержимым файла.
4. Нажмите **Только проверить** — файл проверится без сохранения; или сразу **Загрузить**.

Если ошибок нет, создаётся новая **версия набора** (v1, v2, …), исходный файл сохраняется вместе с ней. Если есть ошибки — ничего не сохраняется, а приложение показывает таблицу ошибок с номером строки и столбца: см. [Ошибки при загрузке](help:data-errors).

**Предупреждения** (например, «m2 больше m1», «год даты не совпадает с годом») не мешают загрузке, но значения стоит проверить.

## Состояние наборов

В таблице наборов для каждого типа видно: статус (версия или «не загружен»), число строк, период (годы), дату последнего изменения. Если после последнего расчёта данные изменились, водоём на карте станет оранжевым.

## Перенос данных из прежних файлов

Данные, которые заказчик вёл в файлах Python (`*_catch_YYYY.py`, `*_fish_prop.py`, `*_npc_assessment.py`), переносятся в шаблоны командой `tools/legacy_to_excel.py` (это делает администратор, см. [Первый запуск и загрузка данных](help:first-start)).

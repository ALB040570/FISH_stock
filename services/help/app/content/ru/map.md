# Карта водоёмов

Главная страница приложения. Слева — список водоёмов с фильтрами, справа — карта Казахстана.

## Цвет водоёма

| Цвет | Состояние |
|---|---|
| серый | нет данных |
| синий | данные загружены, основных расчётов ещё нет |
| зелёный | есть основные расчёты, они актуальны |
| оранжевый | основные расчёты устарели (новые данные или пересчитан вход) — пора пересчитать |

## Подложка

Карта показывает только территорию Казахстана, за границей — пустой фон. Переключатель **Подложка** под легендой:

- **Карта** — подробная карта OpenStreetMap (реки, населённые пункты, дороги); нужен доступ в интернет;
- **Без подложки** — только контур страны и водоёмы; работает без интернета, удобно для отчётов.

Выбор запоминается в браузере.

## Фильтры

- **Поиск** по названию.
- **Область**, **Состояние**, **Вид водоёма** (озеро, водохранилище, …), **Статус** для отрасли, **Тип** (естественный или искусственный), **Вид в данных** — например, показать только водоёмы, где в данных есть судак. Водоём, лежащий в нескольких областях (Балхаш), находится по любой из них.

## Панель водоёма

Щелчок по водоёму на карте или в списке открывает панель: вид водоёма и области (если заполнены — статус, тип и виды ведения рыбного хозяйства), годы данных, число наборов, виды в данных, основные расчёты (буквы алгоритмов, дата, сколько устарело), ПДУ последнего года. Кнопки:

- **Мониторинг** — графики и таблицы по водоёму ([Мониторинг водоёма](help:monitoring));
- **Данные** — наборы данных водоёма ([Загрузка данных](help:data-upload));
- **Запустить расчёт** — расчёты водоёма ([Расчёты](help:calculations)).

## Новый водоём

Если водоёма нет на карте, его добавляют в справочник «Водоёмы» — см. [Добавление водоёма](help:water-body). 37 крупных водоёмов внесены заранее (контуры — открытые данные Natural Earth); координаты и контуры можно уточнить.

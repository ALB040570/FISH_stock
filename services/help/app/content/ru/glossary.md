# Глоссарий

| Термин | Қазақша | Значение |
|---|---|---|
| ПДУ — предельно допустимый улов | ШРА — шекті рұқсат етілген аулау көлемі | объём вылова вида за год, который не подрывает воспроизводство запаса, т |
| ПДУ НПЦ | ҒӨО ШРА | ПДУ, установленный Научно-производственным центром рыбного хозяйства (исходные данные) |
| НПЦ | ҒӨО | Научно-производственный центр рыбного хозяйства |
| Запас | Қор | численность рыб вида в водоёме, шт (по возрастам) |
| Промысловая биомасса | Кәсіптік биомасса | масса половозрелых рыб (возраст от m0), т |
| Улов | Ауланым | число пойманных рыб за лов, шт |
| Лов | Аулау | один замёт невода или одна постановка сети |
| Научный / промысловый / спортивно-любительский лов | Ғылыми / кәсіпшілік / спорттық-әуесқойлық аулау | тип лова (справочник «Типы вылова») |
| Место лова | Аулау орны | место лова на водоёме (справочник «Места лова») |
| Код ТОФИ | ТОФИ коды | код значения в классификаторе «Факторы» ТОФИ, по которому заполнены справочники-классификаторы |
| Невод | Сүзекі | активное орудие лова; запас по нему считается методом площадей |
| Сеть | Ау | пассивное орудие лова; запас по нему считается балансовым методом |
| Улов на усилие (CPUE) | Күшке шаққандағы ауланым | улов, делённый на количество лова: на 100 м сети за постановку или на 1 га облова неводом |
| Урожайное поколение | Өнімді ұрпақ | многочисленное поколение одного года рождения; в возрастном составе — яркая диагональ снизу-слева вверх-вправо |
| Уловистость (коэффициент уловистости) | Аулағыштық | доля рыб в зоне облова, которая попадает в орудие лова |
| Метод площадей | Аудан әдісі | запас = улов на обловленной площади, пересчитанный на площадь водоёма с учётом уловистости невода |
| Балансовый метод | Баланс әдісі | оценка запаса по уловам сетью через модель движения рыб вокруг сети |
| Возраст j | Жас j | возрастная группа от j−1 до j лет (j = 2 — рыбы от 1 до 2 лет) |
| m0 | m0 | возраст половой зрелости; ловятся только рыбы возраста ≥ m0 |
| m1 | m1 | максимальный возраст вида |
| m2 | m2 | возраст, до которого рыба вида служит кормом для хищников |
| Возрастная проба | Жас сынамасы | число рыб, прошедших биологический анализ, по возрастам |
| Окончательный запас | Түпкілікті қор | запас по возрастам, объединяющий оценки по сети и неводу |
| Сеголетки | Шабақтар | рыбы первого года жизни (0–1); в уловах не встречаются, их численность оценивает модель |
| Когортная модель | Когорттық модель | модель, прослеживающая каждое поколение рыб год за годом |
| Байесовский вывод | Байестік қорытынды | оценка параметров модели как распределений с учётом априорных знаний и данных |
| Априорное распределение | Априорлық үлестірім | что известно о параметре до учёта данных (задаётся в профиле водоёма) |
| Апостериорное распределение | Апостериорлық үлестірім | распределение параметра после учёта данных; результат модели |
| Медиана, интервал 50 % / 95 % | Медиана, 50 % / 95 % аралық | середина и границы, в которые попадает 50 % / 95 % выборок модели |
| R̂ (R-hat) | R̂ | показатель сходимости цепей; критерий — не больше 1,01 |
| ESS (эффективный размер выборки) | ESS (іріктеменің тиімді көлемі) | сколько независимых выборок «стоят» цепи модели (bulk — середина распределения, tail — хвосты); критерий — не меньше 400 |
| E-BFMI | E-BFMI | показатель того, насколько хорошо цепь NUTS перемещается по уровням энергии; критерий — больше 0,3 |
| Расходимости | Дивергенциялар | технические сбои выборки NUTS; критерий — ни одной |
| β | β | отношение фактического вылова к ПДУ (учитывает неучтённый вылов) |
| F, M | F, M | промысловая и естественная мгновенная смертность; F = k·M — сценарий прогноза |
| Профиль водоёма | Су айдынының профилі | параметры модели, зависящие от водоёма, по видам |
| Расчёт | Есептеу | наборы данных + цепочка алгоритмов + параметры + форматы результатов |
| Запуск | Іске қосу | одно выполнение расчёта; хранит версии данных и алгоритмов и результаты |
| Основной запуск | Негізгі іске қосу | проверенный запуск водоёма, который показывает мониторинг |
| Набор данных | Деректер жиынтығы | таблица исходных данных одного типа для водоёма, с версиями |
| Версия | Нұсқа | неизменяемое сохранённое состояние объекта |

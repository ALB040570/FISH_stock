# Конструктор дашбордов

**Моделирование → Дашборды** → ваш дашборд (или на открытом дашборде — кнопка **Конструктор**).

## Вкладки

**Добавить вкладку** — название на русском и казахском. Вкладки можно переименовывать и удалять.

## Виджеты

**Добавить виджет** → тип:

| Тип | Для чего |
|---|---|
| Показатель | одно число (например, ПДУ последнего года) |
| Линейный график | ряды по годам или возрастам |
| Столбцы | сравнение значений |
| Таблица | строки данных с поиском |
| Текст | пояснение, заголовок раздела |
| Особое представление | готовые представления методики: кривые уловистости, полоса байесовской модели, разбор ПДУ, сценарии прогноза, сводка данных |
| Представление исходных данных | 27 готовых представлений: улов на усилие, состав улова, охват мест и месяцев, разброс уловов, улов по возрастам, возрастной состав, рост, параметры видов, квоты, качество данных, замечания и др. (см. [Исходные данные в мониторинге](help:monitoring-data)); настраиваются орудие (сеть или невод) и тип лова |

Настройки виджета:

- **Источник**:
  - *Набор данных* — исходные данные водоёма (например, уловы по ловам);
  - *Таблица результатов* — таблица результата основного расчёта алгоритма водоёма (например, «ПДУ НПЦ по возрастам» алгоритма h);
  - *Представление шага* — данные особого представления результата основного расчёта;
- **Ось X** (поле, например `year`), **Значение (Y)** (поле или `$species` — по столбцам видов), **Ряды**, **Агрегирование** (сумма, среднее, количество, последнее);
- **Фильтр строк (JSON)** — например, `{"species": "лещ"}` или `{"year": "$last_year"}` (последний год данных);
- **Ширина (из 12)** и **Высота** — размер на сетке.

## Фильтры дашборда

Значения фильтров (водоём, вид) подставляются в источники виджетов; `$last_year` в фильтре строк — последний год данных. Для сравнения нескольких водоёмов отметьте **Водоёмы для сравнения** и в настройках виджета выберите «по всем выбранным водоёмам» — см. [Сравнение водоёмов](help:compare).

## Подзаголовки и разделы

У виджета есть **подзаголовок** на русском и казахском — короткая фраза о том, что он показывает и зачем. Вкладка может делиться на **разделы** (как «Исходные данные» в мониторинге); раздел виджета выбирается в его настройках. Пороги списка «На что обратить внимание» задаются отдельно — [Правила замечаний](help:signal-rules).

## Сохранение

**Сохранить** — новая версия дашборда; выберите доступ: только мне / всем пользователям.

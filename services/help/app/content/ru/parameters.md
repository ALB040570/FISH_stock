# Три категории параметров

Каждый параметр алгоритма относится к одной из трёх категорий.

| Категория | Что это | Где задаётся | Кто меняет |
|---|---|---|---|
| **Неизменяемые** (`fixed`) | константы методики: границы уловистости, доля изъятия за итерацию, формула объединения сети и невода | в версии алгоритма | только новой версией алгоритма (математик) |
| **Зависящие от водоёма** (`waterbody`) | параметры, подобранные под водоём и вид: априорные распределения байесовской модели, варианты формул по видам | в **профиле водоёма** | ихтиолог, математик, администратор; каждое сохранение — версия профиля |
| **Параметры запуска** (`run`) | то, что меняют от расчёта к расчёту: виды, число выборок, горизонт прогноза, k, фиксированный ПДУ | в расчёте или при запуске | кто запускает расчёт |

Почему так: неизменяемые параметры — часть методики, их нельзя случайно поменять в отдельном расчёте; параметры водоёма хранятся отдельно и с версиями, чтобы для каждого водоёма был свой проверенный набор; параметры запуска позволяют проверять сценарии, не трогая методику.

Если в расчёте попытаться задать неизменяемый параметр, приложение откажет с сообщением «… — неизменяемый параметр методики; меняется только новой версией алгоритма».

В каждом запуске сохраняются итоговые значения всех параметров (вкладка **Параметры** шага) и версия профиля.

Параметры каждого этапа с их значениями по умолчанию перечислены в статьях раздела [Методика расчёта](help:method-overview).

# Каталог алгоритмов

**Расчёты запасов рыб → Каталог алгоритмов** — абстрактные алгоритмы расчёта запасов рыб и ПДУ. У каждого — входы, результаты и параметры; реализация — версии кода. **Расчёт** — алгоритм с конкретными входами, периодом и параметрами (см. [Расчёты](help:calculations)).

| | Алгоритм | Входы | Результат |
|---|---|---|---|
| a | Уловистость сети по возрастам и годам | уловы, пробы, параметры видов, условия | коэффициенты c сети, параметры парабол |
| b | Уловистость невода по возрастам и годам | те же | коэффициенты c невода, параметры сигмоид |
| c | Правдоподобие методом площадей (уловы неводом) | данные; **b** | оценка запаса по каждому лову неводом |
| d | Правдоподобие балансовым методом (уловы сетью) | данные; **a** | σ балансовой модели, оценка запаса по каждому лову сетью |
| e | Ежегодный запас методом площадей (шт и т) | **c**, средние веса | годовой запас неводом по возрастам |
| f | Ежегодный запас балансовым методом (шт и т) | **d**, средние веса | годовой запас сетью по возрастам |
| g | Ежегодный запас, усреднённый по неводу и сети (шт и т) | **e**, **f**, оценка НПЦ | окончательный запас по возрастам, сравнение с НПЦ |
| h | ПДУ в экземплярах особей | **g**, ПДУ НПЦ | ПДУ НПЦ по возрастам в штуках, промысловая биомасса |
| i | Запас по математической модели | **c**, **d**, **g**, **h** | численность по возрастам и годам с интервалами, диагностика |
| j | Прогноз запаса и оценка ПДУ по модели | **i** | прогноз по сценариям, ПДУ по модели |
| k | Оценка ПДУ на основе коэффициента изъятия | **g** | ПДУ, т = промысловый запас × коэффициент изъятия — *планируется* |

Запас по уловам считается **с учётом возрастов** (уловистость по возрастным группам). Способ годового запаса — *по запасам* (среднее оценок по ловам) или *по улову* — параметр алгоритмов e и f. Тонны — запас × средний вес возраста года: все возрасты и промысловые (возраст ≥ m0).

## Карточка алгоритма

Буква, название, код, описание, входы (ссылки на алгоритмы), наборы данных, результаты, **тип модели** и **метод расчёта запаса** (классификатор ТОФИ), последняя версия, кнопки **Запустить**, **Расчёты алгоритма**, **Наборы параметров** и разделы:

- **Параметры** — код, название, тип, где задаётся (*параметр алгоритма* — в наборе параметров, *в расчёте* — виды) и значение по умолчанию;
- **Версии** — номер, состояние *включена / отключена*, источник (*эталонный* или опубликован из «Конструктор → Алгоритмы»), дата, контрольная сумма, **Код версии** (просмотр) и zip.

Код, пакет и параметры видны всем, кроме роли «Презентация».

## Включить и отключить версию

Версии кода включает и отключает **администратор и математик**. Отключённая версия не предлагается в расчётах; расчёты с «последней включённой» версией берут самую новую включённую — их результаты становятся устаревшими. Расчёт с закреплённой отключённой версией не запускается, пока версию не включат или не выберут другую.

## Версии и воспроизводимость

Версия кода неизменяема: код и контрольная сумма пакета фиксируются при публикации. Значения параметров — отдельно, в [наборах параметров](help:profiles) с версиями. Новая версия кода создаётся через [моделирование алгоритмов](help:algo-dev).

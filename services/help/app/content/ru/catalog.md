# Каталог алгоритмов и версии

**Администрирование → Каталог алгоритмов** — опубликованные проверенные версии алгоритмов. Расчёты используют только версии из каталога.

Для каждого алгоритма видны: название, код, описание, **тип модели** и **метод расчёта запаса**, последняя версия и вкладки:

- **Параметры** — все параметры с категорией (неизменяемый / водоём / запуск), типом и значением по умолчанию;
- **Версии** — список версий: номер, источник (*эталонный* — перенесён из исходной программы заказчика; или опубликован из раздела «Моделирование → Алгоритмы»), дата, автор, отчёт о проверке, статус *включена / отключена*, контрольная сумма;
- **Требует данных** и **Предыдущие шаги** — какие наборы данных и шаги нужны алгоритму;
- **Результаты** — таблицы и файлы, которые он создаёт;
- **Код версии** — файлы пакета (только просмотр).

## Алгоритмы методики

| Код | Этап | Что считает |
|---|---|---|
| `seine_catchability` | 1 | уловистость невода по возрастам и годам |
| `stock_by_catch` | 2 | уловистость сети, запас по каждому лову и годовой окончательный запас |
| `pdu_by_age` | 3 | распределение ПДУ НПЦ по возрастам в штуках |
| `bayes_cohort` | 4 | байесовская когортная модель численности |
| `forecast_pdu` | 5 | прогноз численности и ПДУ по сценариям |

Подробно — раздел [Методика расчёта](help:method-overview).

## Тип модели и метод расчёта запаса

Классификация алгоритма по классификатору ТОФИ:

| Код | Тип модели | Метод расчёта запаса |
|---|---|---|
| `seine_catchability` | детерминированный | метод площадей |
| `stock_by_catch` | детерминированный | метод площадей, балансовый метод |
| `pdu_by_age` | детерминированный | — |
| `bayes_cohort` | стохастический | математическая модель |
| `forecast_pdu` | стохастический | математическая модель |

Каталог можно отфильтровать по типу модели и методу. Математик и администратор меняют классификацию значком карандаша рядом с ней (например, для нового алгоритма); на расчёты она не влияет.

## Включить и отключить версию

Математик и администратор могут **Отключить** версию — она перестанет предлагаться в расчётах (уже выполненные запуски не меняются). **Включить** возвращает её. Расчёт с шагом «последняя включённая» берёт самую новую включённую версию; расчёт с закреплённой версией — именно её.

## Версии и воспроизводимость

Версия алгоритма неизменяема: код, параметры по умолчанию и контрольная сумма пакета фиксируются при публикации. В каждом запуске записывается версия и контрольная сумма, поэтому всегда известно, каким кодом получен результат. Новая версия создаётся только через [моделирование алгоритмов](help:algo-dev).

# Этап 2. Запас по уловам: метод площадей и балансовый метод

## Простыми словами

По каждому лову оценивается, сколько рыб каждого возраста во всём водоёме:

- **невод** обловил известную площадь — улов, делённый на уловистость, даёт плотность рыбы, которую переносим на весь водоём (**метод площадей**);
- **сеть** стоит в одной точке, рыба приходит к ней сама — модель движения рыбы вокруг сети показывает, с какой площади за время стоянки собирается улов (**балансовый метод**).

Оценки по отдельным ловам усредняются за год, затем оценки сети и невода объединяются в **окончательный запас** по возрастам. Оценки по каждому лову служат наблюдениями для байесовской модели (этап 4), окончательный запас — основой распределения ПДУ НПЦ (этап 3).

## Невод: метод площадей

Для лова $d$ года $t$, вида и возраста $j$:

$$\tilde X^{2}_{j}(d) = \frac{Y^{2}_{j}(d)\; S(t)}{c^{2}_{j}(t)\; s_{area}(d)}$$

$S(t)$ — площадь водоёма, м²; $s_{area}(d)$ — обловленная площадь, м²; $c^{2}_{j}(t)$ — уловистость невода (этап 1).

## Сеть: балансовый метод

**Модель движения рыбы.** Вокруг сети длиной $L$ строятся круг 0 радиусом $r_0 = L/2$ и кольца шириной $V$ — путь рыбы за час ($V = 3600\, v$, $v$ — крейсерская скорость вида, м/с): кольцо 1 — до радиуса $V$, кольцо $k$ — от $(k-1)V$ до $kV$. Колец столько, сколько часов стоит сеть ($T$). Численность задаётся в долях рыб первого круга (площадь $\pi V^2$ = 1): в круге 0 — $(r_0/V)^2$, в кольце 1 — $1 - (r_0/V)^2$, в кольце $k$ — $2k-1$ (пропорционально площади, плотность одинакова).

Каждый час:

- из каждой области 1/4 рыб движется к сети (внутрь), 1/4 — от сети (наружу), 1/2 остаётся;
- через границу круга 0 и кольца 1 потоки делятся пропорционально длинам границ: внутрь уходит доля $r_0/(r_0+V)$ половины «движущихся», наружу — $V/(r_0+V)$; между кольцами $k-1$ и $k$ — доли $(k-1)/(2k-1)$ и $k/(2k-1)$;
- из рыб круга 0, двинувшихся к сети, доля $c$ (уловистость сети) попадает в сеть, остальные остаются в круге 0;
- внешнее кольцо закрыто: рыба, уходящая наружу, остаётся в нём.

После $T$ часов $\sigma(c)$ — доля рыб первого круга, оказавшихся в сети. Модель считается для каждой уловистости $c^{1}_{j}(t)$, вида и года.

**Запас по лову сетью:**

$$\tilde X^{1}_{j}(d) = \frac{Y^{1}_{j}(d)\; S(t)}{\sigma\left(c^{1}_{j}(t)\right)\,\left(V^2 - r_0^2\right)}$$

Знаменатель — площадь облова (м²), умноженная на долю пойманных. Вариант формулы задаёт неизменяемый параметр `NET_STOCK_FORMULA`: `code` — как выше (принят в версии 1.0.x), `article` — со знаменателем $\pi V^2 \sigma$.

## Годовой запас

Два варианта уловистости:

- **с учётом возрастов** — коэффициенты $c_{j}(t)$ этапов 1 и 2 (основной вариант);
- **без учёта возрастов** — одна средняя уловистость вида $\bar c$ для всех возрастов (для сравнения).

Два способа годовой оценки:

- **по запасам** — среднее оценок по ловам года (основной способ);
- **по годовому улову** — невод: $\sum Y^{2}(d)\, S \,/\, (c^{2} \sum s_{area}(d))$; сеть: средний улов на лов в формуле запаса по сети.

**Окончательный запас** по возрасту объединяет сеть и невод с весами по числу ловов $N^{1}(t)$, $N^{2}(t)$, в которых вид учитывался:

$$\tilde X_{j}(t) = \frac{N^{1}(t)\, \tilde X^{1}_{j}(t) + N^{2}(t)\, \tilde X^{2}_{j}(t)}{N^{1}(t) + N^{2}(t)}$$

Если у одного орудия оценки нет (например, на водоёме ловили только сетями), берётся оценка другого. Способ объединения задаёт параметр `COMBINE_GEARS`: `hauls` — по числу ловов (как выше), `mean` — простое среднее.

**Суммарный запас** вида — сумма окончательных запасов по возрастам 2…$m_1$. Где уловистость равна нулю (возрасты старше $m_1$), запас принимается равным нулю.

Оценка запаса НПЦ (тыс. шт) умножается на 1000 и показывается рядом для сравнения.

## Результаты

- запас по каждому лову (сеть и невод, оба варианта уловистости);
- годовой запас по орудиям, вариантам и способам; окончательный запас по возрастам;
- таблица суммарного запаса по видам и годам: сеть, невод, окончательный, число ловов, оценка НПЦ;
- кубы NetCDF, Excel.

# Параметры алгоритмов: что означает каждый

Здесь собраны все параметры алгоритмов a–j с пояснением простыми словами: что параметр означает, зачем он нужен и на что повлияет его изменение. Те же пояснения показываются на экране **Расчёт запасов рыб → Параметры алгоритмов** под названием каждого параметра (переключатель «Пояснения к параметрам»).

## Как устроены параметры

- **Набор «По умолчанию (эталон 22.10.2026)»** — значения из статьи и эталонного расчёта. Он не меняется: с ним результаты совпадают с контрольными примерами.
- **Свой набор** создаётся кнопкой **Создать на основе** и меняется новыми версиями; прежние версии сохраняются. Набор общий — его можно указать в расчёте любого водоёма.
- **Где задаётся** (столбец таблиц): «набор "Параметры алгоритма"» — значение берётся из набора; «в расчёте» — выбирается при создании расчёта (виды модели и прогноза).

## Когда и как менять

Значения по умолчанию менять без причины не нужно. Обычные причины:

- модель не сошлась ($\hat R$ > 1,01, расходимости) — настройки выборки или профили видов алгоритма i ([Как проверить результат модели](help:method-diagnostics));
- математик проверяет гипотезу — например, другие края параболы сети или границы уловистости невода;
- для водоёма нужны другие условия — например, площадь водоёма в прогнозные годы (алгоритм j).

Порядок: создать набор на основе «По умолчанию» → изменить значения и сохранить с комментарием «что и почему» → создать расчёт с этим набором (он будет **альтернативным**) → сравнить результат с основным → при необходимости **сделать основным**. После этого расчёты, которые берут его результат, станут **устаревшими** — их пересчитывают кнопкой «Пересчитать устаревшие». Какой набор и какой версии использовался, записано в журнале каждого расчёта.

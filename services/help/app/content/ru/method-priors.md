# Априорные распределения и профиль водоёма

Профиль водоёма задаёт для каждого вида априорные распределения неизвестных величин байесовской модели и варианты формул. Значения по видам смотрите и меняйте в разделе [Параметры водоёмов](help:profiles); ниже — что означает каждый параметр.

Обозначения: $\mathrm{LogN}(\mu, \sigma)$ — логнормальное распределение ($\ln x \sim \mathcal{N}(\mu, \sigma)$); $\mathcal{N}_{[a,b]}$ — нормальное, усечённое до $[a, b]$; $\mathrm{U}[a, b]$ — равномерное; $\mathrm{Beta}(\alpha, \beta)$ — бета-распределение.

## Естественная смертность

| Параметр профиля | Величина | Распределение / смысл |
|---|---|---|
| База смертности: μ ln, σ | $s_{base}$ | $\mathrm{LogN}(\mu, \sigma)$ — смертность средних возрастов (минимум кривой); μ = −2,2 соответствует ≈ 11 % в год |
| Крутизна для молоди: μ ln, σ | $s_{juv}$ | $\mathrm{LogN}$ — насколько быстро растёт смертность к младшим возрастам |
| Крутизна для старших: μ ln, σ | $s_{age}$ | $\mathrm{LogN}$ — рост смертности к старшим возрастам |
| Годовые колебания: σ | $f(t)$ | $\mathcal{N}(0, \sigma)$ — смещение всей кривой смертности в отдельный год (заморы, уровень воды) |
| Нормировка на максимум | — | доля от теоретического максимума кривой |
| Нижняя / верхняя граница s | — | обрезка значений смертности (например, 0 и 0,95) |
| Обрезка s | — | по нормированной кривой или с переключением по максимуму (карась, язь) |

## Хищники

| Параметр | Величина | Смысл |
|---|---|---|
| γ_max: доля гибели от хищников у сеголетков | $\gamma_{max}$ | давление хищников $\gamma_j = \gamma_{max}/j$ до возраста $m_2$, постоянное по годам; у большинства видов 0,3, у щуки 0,2 |
| Граница «корм хищников» | $h_j$ | плавная (сигмоида около $m_2$) или ступенька |

## Вылов и браконьерство

| Параметр | Величина | Смысл |
|---|---|---|
| β: μ, σ, нижняя и верхняя граница | $\beta(t)$ | $\mathcal{N}_{[a,b]}(\mu, \sigma)$ для каждого года — отношение фактического вылова к ПДУ (1 — вылов равен ПДУ; больше 1 — неучтённый вылов, меньше 1 — недолов). По умолчанию $\mathcal{N}_{[0{,}9;\ 1{,}4]}(1;\ 0{,}06)$, у леща верхняя граница 1,3, у окуня $\mathcal{N}_{[0{,}7;\ 1{,}4]}(1;\ 0{,}2)$ |
| Вычитание вылова | — | плавное ограничение изъятия долей выживших (у всех видов); для сравнения — плавное (tanh), «не меньше 1 рыбы», «доля вылова ≤ 0,95» — см. [этап 4](help:method-bayes) |
| Изъятие не больше доли выживших | — | предел изъятия, по умолчанию 0,95 |
| Крутизна ограничения изъятия | $k$ | по умолчанию 50: чем больше, тем ближе ограничение к точному минимуму |
| Множитель ПДУ | — | умножает ПДУ по возрастам перед вычитанием (для проверки чувствительности) |

## Пополнение

| Параметр | Величина | Смысл |
|---|---|---|
| Выживаемость икры: Beta α, β, масштаб | $e_0 = k_e \cdot \mathrm{Beta}(\alpha, \beta)$ | доля икры, доживающей до личинки; $k_e$ — масштаб |
| Плодовитость в m0 / m1: ширина интервала | $\theta(m_0) \sim \mathrm{U}[\theta_{min},\ \theta_{min} + w (\theta_{max} - \theta_{min})]$, $\theta(m_1) \sim \mathrm{U}[\theta_{max} - w(\theta_{max} - \theta_{min}),\ \theta_{max}]$ | икринок на самку в возрасте созревания и в максимальном возрасте |
| Сдвиг плодовитости, плодовитость не меньше 0 | — | форма линейной зависимости плодовитости от возраста |
| Кто нерестится | — | все возрасты по доле половозрелых или возрасты от 2 с долей самок 0,5 (щука) |
| Ёмкость по годам: σ | $\alpha(t) \sim \mathrm{LogN}(0, \sigma)$ | годовая изменчивость ёмкости нерестилищ |
| Ограничение мальков ёмкостью | — | с масштабом 100 000 или без масштаба (плотва) |

## Начальный запас

| Параметр | Смысл |
|---|---|
| Начальный запас: σ | $X_j(0) \sim \mathrm{LogN}(\ln \tilde X_j(0), \sigma)$ |
| не меньше / не больше × оценки | допустимый диапазон относительно оценки по уловам первого года |
| Начальный запас по данным | окончательный запас (сеть и невод) или только невод |

## Правдоподобие и формулы

| Параметр | Смысл |
|---|---|
| Сглаживание численности (softplus) | численность после шага остаётся положительной |
| Ловы, где вид не учитывался | исключить (как на этапе 2) или считать нулевым уловом |
| Правдоподобие с возраста j | с какого возраста оценки по ловам входят в наблюдения (от 2 до 6); по умолчанию 3, у плотвы 2, у щуки 4 |
| Нижняя граница ожидаемого запаса | плавная или жёсткая граница 10 рыб |
| Шум наблюдений: σ HalfNormal | априорный масштаб $\sigma_{obs}$ (у карася — коэффициента вариации $\nu$); по умолчанию 0,5, у карася 3 |
| Поправка уловистости q: σ | $u_j \sim \mathcal{N}(0, \sigma)$, $q_j = e^{u_j}$ |
| Поправка уловистости сети q_net | включить поправку $Q_{net}$ для ловов сетью (невод — опорное орудие) |
| ln q_net: σ | $\ln Q_{net} \sim \mathcal{N}(0, \sigma)$, по умолчанию 1 |
| Правдоподобие оценок по ловам | дельта-логнормальное (пустые ловы — отдельная вероятность; основной вариант) или логнормальное с добавкой (у плотвы) |
| Добавка к оценкам по ловам | по умолчанию 0,1: в логнормальном правдоподобии с добавкой прибавляется ко всем оценкам, в дельта-логнормальном — нижняя граница оценок непустого лова |
| Пустые ловы: σ уровня c | $c_g \sim \mathcal{N}(0, \sigma)$, по умолчанию 2 |
| Пустые ловы: μ, σ наклона b | $b \sim \mathcal{N}(\mu, \sigma)$, по умолчанию 1 и 0,5 |
| Ненулевые ловы (дельта) | логнормальное по возрастам (основной вариант), гамма по возрастам (у карася) или логнормальное для суммы по возрастам лова |

## Выборка NUTS

| Параметр | Смысл |
|---|---|
| Выборок на цепь, шагов настройки | по умолчанию 1000 и 1000 |
| Цепей | по умолчанию 4 |
| `target_accept` | по умолчанию 0,95, у карася 0,98; выше — меньше расходимостей, но медленнее |
| `max_treedepth` | по умолчанию 12 |
| Старт цепей | все из одной точки (по умолчанию), с разбросом или из лучшего из нескольких максимумов апостериорной плотности (у окуня) |
| Старт цепей: число точек поиска | сколько случайных точек для поиска максимума, по умолчанию 8 |
| Нецентрированные годовые эффекты (s, β) | другая запись годовых колебаний смертности и $\beta$ с тем же априорным распределением — помогает при расходимостях |
| `seed` | по умолчанию 42 |

Это значения по умолчанию для запуска; в расчёте их можно переопределить.

## Как подбирать значения для нового водоёма

1. Начните с копии профиля Жайсана ([Параметры водоёмов](help:profiles)).
2. Для новых видов задайте значения по биологии вида: базовая смертность взрослых, крутизна для молоди так, чтобы смертность сеголеток была близка к 0,95, крутизна для старших — чтобы к $m_1$ смертность приближалась к 1; доля гибели от хищников $\gamma_{max}$ — по доле хищников в водоёме.
3. Запустите расчёт и проверьте диагностику ([Как проверить результат](help:method-diagnostics)): сходимость, согласие с оценками по уловам, правдоподобность параметров.
4. Сохраните профиль с комментарием — каждая версия профиля фиксируется в запусках.

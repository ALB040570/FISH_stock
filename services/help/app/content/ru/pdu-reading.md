# Как читать вкладку ПДУ

Вкладка **ПДУ** мониторинга показывает итог и то, как он получен.

## ПДУ по видам

Таблица и диаграмма по видам:

- **ПДУ на первый прогнозный год, т (F = k·M)** — медиана ПДУ по прогнозу байесовской модели (этап 5), и **95 % интервал, т**;
- **F** — промысловая смертность этого сценария;
- **ПДУ НПЦ последнего года истории** — официальная квота для сравнения;
- **P(снижение)** — доля траекторий прогноза, в которых численность к концу прогноза ниже последнего года истории. Чем ближе к 100 %, тем выше риск снижения запаса при этом уровне вылова.

Таблица заполняется по запуску с этапом 5 (полный расчёт). Если такого запуска нет, вместо неё — сообщение «В запуске для мониторинга нет этого шага расчёта», а разбор ниже (этап 3) показывается и для быстрого расчёта.

## Из чего сложился ПДУ: запас → возраст → квота

Разбор для выбранного вида и года — четыре шага:

1. **Окончательный запас** (сеть + невод) по возрастам; половозрелые возрасты от m0 до m1;
2. **Промысловая биомасса** — запас × средний вес;
3. **Квота НПЦ** (т) распределяется по половозрелым возрастам пропорционально биомассе с нагрузкой j/m1; за итерацию из возраста изымается не больше 75 % остатка;
4. **ПДУ в штуках по возрастам** и доля изъятия по каждому возрасту.

Таблица по возрастам: запас, средний вес, ПДУ в штуках и тоннах, доля изъятия. Пометка «вес взят от ближайшего младшего возраста» — в данных нет веса этого возраста.

Ссылка **Как получена эта цифра** над разбором ведёт в справку. Подробно и с формулами — [Этап 3. ПДУ НПЦ по возрастам](help:method-pdu-age); пример на числах вашего водоёма — [Пример на числах](help:method-example).

## Прогноз по сценариям

Графики численности и ПДУ на горизонт прогноза (по умолчанию 5 лет) для трёх сценариев:

- **F = k·M** — промысловая смертность пропорциональна естественной (уравнение Баранова), k задаётся в параметрах расчёта;
- **фиксированный ПДУ** — каждый год вылавливается заданный ПДУ (по умолчанию — ПДУ НПЦ последнего года);
- **без промысла** — для сравнения.

Полосы — интервалы 50 % и 95 % по 500 выборкам байесовской модели. Подробнее — [Этап 5. Прогноз и ПДУ](help:method-forecast).

# Правка справки

Править справку могут администратор и математик. Остальные роли читают её и выгружают в Word и PDF.

## Изменить статью

1. Откройте статью → **Изменить**.
2. Выберите язык **РУС** или **ҚАЗ** — у каждой статьи два текста.
3. Правьте текст слева, справа — предпросмотр.
4. Укажите комментарий → **Сохранить**. Каждое сохранение — новая версия; **Версии** показывают историю, любую версию можно открыть и **восстановить**.

Первая строка статьи — заголовок: `# Название`.

## Разметка (Markdown)

| Что | Как писать |
|---|---|
| заголовок раздела | `## Раздел`, `### Подраздел` |
| жирный, курсив | `**жирный**`, `*курсив*` |
| список | `- пункт` или `1. пункт` |
| таблица | строки вида `\| A \| B \|`, вторая строка `\|---\|---\|` |
| ссылка на статью справки | `[текст](help:код-статьи)`, например `[Расчёты](help:calculations)` |
| врезка | строка, начинающаяся с `>` |
| формула в строке | `$X_{ij}(t)$` |
| формула отдельной строкой | `$$ … $$` (подмножество LaTeX: дроби `\frac`, суммы `\sum`, индексы, греческие буквы) |
| код, команда | `` `команда` `` или блок между строками ```` ``` ```` |

## Рисунки и снимки экрана

**Вставить рисунок** → файл PNG, JPEG, GIF или WebP до 10 МБ → в текст вставится строка `![подпись](help-image:…)`. Рисунки попадают и в выгрузку Word/PDF. Места для будущих снимков экрана отмечены врезками «[Снимок экрана: …]».

## Вставки из приложения

Две строки-вставки заполняются автоматически при чтении и выгрузке:

- `{{params:<код алгоритма>}}` — таблица параметров последней включённой версии алгоритма (например, `{{params:pdu_by_age}}`);
- `{{example}}` — пример распределения ПДУ по возрастам на числах выбранного водоёма (из запуска для мониторинга).

## Обновление приложения

Тексты справки поставляются вместе с приложением. При обновлении статьи, которые никто не правил, обновляются сами. Если статью правили в приложении, ваша правка сохраняется, а у статьи появляется пометка ↻ и предложение **Взять текст новой версии**.

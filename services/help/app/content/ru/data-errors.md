# Ошибки при загрузке и как их исправить

Если файл не прошёл проверку, приложение показывает таблицу: **Строка**, **Столбец**, **Сообщение**. Номер строки — как в Excel (строка 1 — заголовки). Исправьте файл и загрузите снова; проверку можно повторять кнопкой **Только проверить**.

| Сообщение | Что сделать |
|---|---|
| Файл не читается как Excel (.xlsx) | сохраните файл как «Книга Excel (.xlsx)»; формат .xls и .csv не принимается |
| Лист пуст: нет строки заголовков | первая строка листа «Данные» — заголовки столбцов |
| Столбец «…»: такого столбца нет в типе … | проверьте написание заголовка; если это вид рыбы — добавьте вид в справочник «Виды рыб» |
| Столбец «…» повторяется | удалите повторный столбец |
| Нет обязательного столбца «…» | добавьте столбец (возьмите заголовок из шаблона) |
| «…»: обязательное поле не заполнено | заполните ячейку |
| «…»: нужно целое число / нужно число, получено «…» | уберите из ячейки текст, единицы, лишние пробелы |
| «…»: дата должна быть в виде ДД.ММ.ГГГГ | исправьте дату |
| «…»: значение «…» не из списка | выберите значение из выпадающего списка |
| «…»: «…» нет в справочнике «…» | орудие лова, тип лова (научный, промысловый, спортивно-любительский лов) или вид должны быть в справочнике; исправьте написание или добавьте запись (для типа лова — другое написание) |
| не меньше … / не больше … | значение вне допустимых пределов (например, уловистость от 0 до 1) |
| Повтор строки с тем же ключом (…) | в наборе уже есть строка с тем же годом/возрастом/видом — удалите дубликат |
| m0 не может быть больше m1 | возраст половой зрелости не может быть больше максимального возраста |
| Минимальная плодовитость больше максимальной | поменяйте значения местами |

Предупреждения (жёлтые) не мешают загрузке:

- **m2 больше m1** — кормом хищников считаются все возрасты вида; проверьте значение;
- **Год даты … не совпадает с годом …** — дата лова и столбец «Год» относятся к разным годам; строка учитывается в году из столбца «Год»;
- **Места «…» нет в справочнике «Места лова» этого водоёма** — проверьте написание или добавьте место (или другое написание) в справочник, см. [Места лова](help:fishing-places).

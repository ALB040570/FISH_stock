# Выгрузка: Excel, NetCDF, отчёт Word/PDF

| Что | Где | Формат |
|---|---|---|
| Набор исходных данных (любая версия) | Сбор данных → Исходные данные → набор → **Excel** | .xlsx в формате шаблона |
| Исходный файл загрузки | Сбор данных → Исходные данные → набор → **Исходный файл** | файл, который загружали |
| Таблица результатов шага | Запуск → шаг → **Таблицы** → **CSV** | .csv |
| Файлы шага | Запуск → шаг → **Файлы** | Excel, NetCDF (.nc), CSV |
| Все результаты запуска | Запуск → **Все результаты (zip)** | .zip: сведения о запуске (run.json), файлы и журналы всех шагов |
| Отчёт по запуску | Запуск → **Отчёт Word** / **Отчёт PDF** | .docx / .pdf |
| Журнал действий | Журнал действий → **Выгрузить в Excel** | .xlsx (только администратор) |
| Руководство пользователя | Справка → **Скачать руководство** | .docx / .pdf |

## NetCDF

Файлы .nc содержат трёхмерные массивы «год × вид × возраст» (уловистость, запас, ПДУ в штуках) с подписями осей — их открывают Python (xarray), R, Panoply, QGIS. Имена переменных совпадают с прежними файлами заказчика.

## Отчёт

Отчёт по запуску собирается автоматически из результатов: сведения о расчёте и версиях, ПДУ по видам, запас, ПДУ НПЦ по возрастам, диагностика модели. Для полного отчёта нужен запуск этапов 1–5; для запуска этапов 1–3 разделы прогноза будут пустыми.

# Выгрузка: Excel, NetCDF, отчёт Word/PDF

| Что | Где | Формат |
|---|---|---|
| Набор исходных данных (любая версия) | Сбор данных → Исходные данные → набор → **Excel** | .xlsx в формате шаблона |
| Исходный файл загрузки | Сбор данных → Исходные данные → набор → **Исходный файл** | файл, который загружали |
| Таблица результата расчёта | Расчёт → **Таблицы** → **CSV** | .csv |
| Файлы расчёта | Расчёт → **Файлы** | Excel, NetCDF (.nc), CSV |
| Результат расчёта | Расчёт → **Скачать** → **Результат (zip)** | .zip: сведения о расчёте (calc.json), журнал расчёта (journal.json), файлы и протокол выполнения |
| Отчёт водоёма | Расчёт → **Скачать** → **Отчёт водоёма Word / PDF** | .docx / .pdf — по основным расчётам водоёма |
| Журнал действий | Журнал действий → **Выгрузить в Excel** | .xlsx (только администратор) |
| Руководство пользователя | Справка → **Скачать руководство** | .docx / .pdf |

## NetCDF

Файлы .nc содержат трёхмерные массивы «год × вид × возраст» (уловистость, запас, ПДУ в штуках) с подписями осей — их открывают Python (xarray), R, Panoply, QGIS. Имена переменных совпадают с прежними файлами заказчика.

## Отчёт

Отчёт водоёма собирается автоматически из основных расчётов: сведения о расчётах (алгоритм, версия, параметры, период, устарел ли), ПДУ по видам, запас в штуках и тоннах, ПДУ НПЦ по возрастам, диагностика модели. Без основных расчётов модели (i) и прогноза (j) соответствующие разделы будут пустыми.

# Запуски и результаты

**Запуск** — одно выполнение расчёта. В нём навсегда сохраняются: автор, время, версии наборов данных, версии и контрольные суммы алгоритмов, версия профиля, параметры, результаты каждого шага, журнал и ошибки. Запуски не перезаписываются — любой результат можно воспроизвести.

## Список запусков

**Запуски**: очередь (сколько ждут и сколько выполняется), фильтры по водоёму и статусу, таблица: начало, расчёт, водоём, шаги, статус, автор, сообщение. ★ — основной запуск водоёма.

| Статус | Значение |
|---|---|
| в очереди | ждёт свободного воркера; показано место в очереди |
| выполняется | идёт шаг; показан ход выполнения |
| выполнен | все шаги выполнены |
| ошибка | шаг завершился с ошибкой; последующие шаги пропущены |
| отменён | запуск отменён пользователем |

Шаги: *ожидает*, *выполняется*, *выполнен*, *ошибка*, *пропущен*, *повторно использован* (взят из предыдущего запуска).

## Страница запуска

- **Ход выполнения** — этап и доля выполнения текущего шага (для байесовской модели — вид и цепочки).
- **Отменить** — остановить запуск (выполняющийся шаг прерывается).
- **Сделать основным** — отметить проверенный запуск как основной для водоёма; его показывает мониторинг. Если основного нет, мониторинг показывает последний успешный запуск с пометкой.
- **Все результаты (zip)**, **Отчёт Word**, **Отчёт PDF**.
- **Наборы данных** и **контрольная сумма пакета** алгоритма — какие именно данные и код использованы.

Для каждого шага вкладки:

- **Представление** — графики и пояснения шага (те же, что в мониторинге);
- **Таблицы** — таблицы результатов с поиском; кнопка **CSV** скачивает таблицу;
- **Файлы** — Excel, NetCDF, CSV шага;
- **Параметры** — итоговые параметры шага (с учётом значений по умолчанию и профиля);
- **Журнал** — сообщения алгоритма, предупреждения, ошибки.

На вкладке **Таблицы** над таблицей — **показатели** шага (например, R̂ и число расходимостей байесовской модели) и **примечания** (например, «вес взят от ближайшего младшего возраста»). Ссылка **Методика этого шага** справа открывает описание этапа в справке.

## Если запуск завершился с ошибкой

Откройте шаг с ошибкой → **Журнал**. Частые причины:

- нет данных по виду или году (проверьте наборы данных);
- нет профиля водоёма для байесовской модели;
- в возрастной пробе вида слишком мало рыб — алгоритм берёт пробу за все годы и пишет об этом в примечаниях (это не ошибка).

Исправьте данные или параметры и запустите расчёт снова.

## Отчёт Word / PDF

Отчёт содержит: сведения о расчёте (водоём, автор, даты, версии алгоритмов и наборов данных), ПДУ по видам на первый прогнозный год с 95 % интервалом и ПДУ НПЦ, запас по уловам и по байесовской модели, ПДУ НПЦ по возрастам, диагностику модели и ограничения.

# Порядок работы: от данных до ПДУ

Ниже — обычная последовательность действий для водоёма. Каждый шаг описан в своей статье.

1. **Водоём в справочнике.** Найдите водоём на карте или добавьте его: название, тип, область, точка на карте. → [Добавление водоёма](help:water-body)
2. **Виды и орудия лова.** Проверьте, что в справочнике «Виды рыб» есть все виды из ваших данных; при необходимости добавьте. → [Справочники](help:dictionaries)
3. **Исходные данные.** Загрузите семь наборов данных по шаблонам Excel: уловы по ловам, возрастные пробы, средний вес по возрастам, биологические параметры видов, условия по годам, оценка запаса НПЦ, ПДУ НПЦ. → [Загрузка данных](help:data-upload)
4. **Расчёты алгоритмов.** В кабинете «Расчёты запасов рыб» запустите алгоритмы каталога по порядку: a, b (уловистость) → c, d (правдоподобие) → e, f (годовой запас по орудиям) → g (усреднённый запас) → h (ПДУ в штуках) → i (модель) → j (прогноз и ПДУ). Можно поставить их в очередь сразу — каждый ждёт свои входы. Проще всего — кнопка **Запустить** в каталоге (параметры «По умолчанию»). → [Расчёты](help:calculations), [Каталог алгоритмов](help:catalog)
5. **Параметры.** Для модели (i) у видов водоёма должны быть значения в наборе параметров; для своих значений создайте набор на основе «По умолчанию». → [Параметры алгоритмов](help:profiles)
6. **Результаты.** Страница расчёта — графики, таблицы, файлы, журнал; отчёт водоёма Word/PDF. → [Результат и журнал расчёта](help:runs)
7. **Основной расчёт.** Первый результат алгоритма водоёма — основной; альтернативный расчёт (другие параметры, период) можно сделать основным. → [Расчёты](help:calculations)
8. **Мониторинг.** Мониторинг водоёма собран из основных расчётов: исходные данные, уловистость, запасы, ПДУ и прогноз. → [Мониторинг](help:monitoring), [Как читать вкладку ПДУ](help:pdu-reading)

Если данные изменились или пересчитан вход, расчёты станут **устаревшими** (на карте — оранжевый цвет) — нажмите **Пересчитать устаревшие**. Журнал расчёта хранит, чем считали каждый раз.

Как устроен сам расчёт — в разделе [Методика расчёта](help:method-overview).

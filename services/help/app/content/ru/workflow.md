# Порядок работы: от данных до ПДУ

Ниже — обычная последовательность действий для водоёма. Каждый шаг описан в своей статье.

1. **Водоём в справочнике.** Найдите водоём на карте или добавьте его: название, тип, область, точка на карте. → [Добавление водоёма](help:water-body)
2. **Виды и орудия лова.** Проверьте, что в справочнике «Виды рыб» есть все виды из ваших данных; при необходимости добавьте. → [Справочники](help:dictionaries)
3. **Исходные данные.** Для водоёма загрузите семь наборов данных по шаблонам Excel: уловы по ловам; рыбы, подвергнутые биологической обработке; средний вес по возрастам; биологические параметры видов; условия по годам; оценка запаса НПЦ; ПДУ НПЦ. → [Загрузка данных](help:data-upload)
4. **Профиль водоёма.** Для байесовской модели (этап 4) нужен профиль параметров водоёма — его готовит математик. Без профиля можно считать этапы 1–3. → [Параметры водоёмов](help:profiles)
5. **Расчёт.** Создайте расчёт из шаблона: «Запас по уловам и ПДУ НПЦ по возрастам (этапы 1–3)» — быстрый, «Полный расчёт ПДУ (этапы 1–5)» — с байесовской моделью и прогнозом. Проверьте готовность и запустите. → [Расчёты](help:calculations)
6. **Результаты.** Дождитесь окончания запуска (страницу можно закрыть), посмотрите результаты шагов, выгрузите Excel, NetCDF, отчёт Word/PDF. → [Запуски и результаты](help:runs)
7. **Основной запуск.** Проверенный запуск отметьте основным — его показывает мониторинг. → [Запуски и результаты](help:runs)
8. **Мониторинг.** Откройте мониторинг водоёма: исходные данные, уловистость, запасы, ПДУ и прогноз. → [Мониторинг](help:monitoring), [Как читать вкладку ПДУ](help:pdu-reading)

Если данные изменились, водоём на карте станет оранжевым — запустите расчёт заново. Прежние запуски сохраняются.

Как устроен сам расчёт — в разделе [Методика расчёта](help:method-overview).
